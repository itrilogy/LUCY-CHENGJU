# scatter (相关分析/散点图) 协议切片

## 1. 专家灵魂 (The Soul)

### 相关与回归

散点图用于验证 X 与 Y 是否存在线性/非线性相关，是「确认原因」阶段的核心工具。

- **相关 ≠ 因果**：观察到相关后仍需排除第三变量，或在专业上给出机理解释。
- **离群点优先追查**：偏离主群的少数点往往对应特殊原因（特定机台、班次、批次）。
- **趋势线**：开启 `ShowTrend` 后由引擎做最小二乘拟合。
- **分组对比**：若疑似存在两个总体（如两台设备），它们会在图上呈现为两团 —— 这是最有价值的信息。

> [!TIP]
> 点太少（< 20）时不要解读趋势线的斜率，容易过拟合；样本点越密集，趋势线越可信。

## 2. 语法血肉 (The Flesh)

### IQS-DSL v1 — scatter (TupleList)

| 语法 | 说明 | 示例 |
| :--- | :--- | :--- |
| `Title:` | 图表标题 形如 `<文本>` **必填** | `Title: 注塑工艺参数相关分析` |
| `XAxis:` | X 轴标签（**含单位**，如 `模具温度(℃)`） 形如 `<文本>` | `XAxis: 模具温度(℃)` |
| `YAxis:` | Y 轴标签（含单位） 形如 `<文本>` | `YAxis: 注射压力(MPa)` |
| `ZAxis:` | Z 轴标签（仅在三维模式 / 气泡图时有意义） 形如 `<文本>` | `ZAxis: 收缩率%` |
| `ShowTrend:` | 显示最小二乘趋势线（true / false） | `ShowTrend: true` |
| `Show3D:` | 启用三维散点视图（兼容别名 `3D` 效果相同）（true / false） | `Show3D: false` |
| `ShowValues:` | 在点旁显示数值标签（true / false） | `ShowValues: false` |
| `Color[Point | Trend]` | #HEX 颜色：数据点 / 趋势线 | `Color[Point]: #0D5E42` |
| `Size[Base]` | 数据点基准像素大小（气泡模式下作为尺寸下限） 形如 `<数值>` | `Size[Base]: 8` |
| `Opacity:` | 数据点透明度（点密集时降低可缓解叠色） 形如 `0–1 之间的数值` | `Opacity: 0.6` |
| `数据行:` | 一个观测点 —— 本 kind 唯一的数据录入方式 形如 `- <X>, <Y>[, <Z>]` **必填** | `- 195.5, 85.2, 2.4` |

### 边界说明

- **`ZAxis`**：二维模式下数据行的第三个数仅作气泡尺寸，不产生 Z 轴。
- **`Show3D`**：开启后数据行需带第三个数（Z 值）。
- **`数据行`**：用**半角逗号**分隔；同一张图内所有行的字段数必须一致（要么都 2 个、要么都 3 个）。

### 反例（错 → 对）

- 错：`- 195.5, 85.2\n- 192.0, 82.5, 2.5`
  对：`- 195.5, 85.2, 2.4\n- 192.0, 82.5, 2.5`
  因：同一张图内每行的字段数必须一致；混用二维与三维会让部分点无法定位。
- 错：`Show3D: true\n- 195.5, 85.2`
  对：`Show3D: true\n- 195.5, 85.2, 2.4`
  因：开启三维后每行都需要第三个数值（Z）。
- 错：`XAxis: 模具温度   （无单位）`
  对：`XAxis: 模具温度(℃)`
  因：轴标签应带单位，否则趋势线的斜率无法解读。
- 错：`（只有 6 个点）ShowTrend: true 并据此断言强相关`
  对：`样本量 ≥ 20 再解读趋势线与相关性`
  因：极少样本下趋势线极不稳定，容易得出误导性结论。
- 错：````dsl\nTitle: xxx\n````
  对：`Title: xxx`
  因：禁止 Markdown 代码围栏 —— 只输出纯文本 DSL。
- 错：`{"Title": "xxx"}`
  对：`Title: xxx`
  因：`dsl` 必须是纯文本字符串，不是 JSON 对象。
- 错：`这是根据您的需求生成的图表：\nTitle: xxx`
  对：`Title: xxx`
  因：禁止解释性前后缀。

## 3. 官方示例 (The Seed)

### 场景：注塑工艺参数相关分析

```dsl
Title: 注塑工艺参数相关分析
XAxis: 模具温度(℃)
YAxis: 注射压力(MPa)
ZAxis: 收缩率%
Color[Point]: #0D5E42
Color[Trend]: #F1C40F
ShowTrend: true
Show3D: false
ShowValues: false

// 数据点：- <X>, <Y> [, <Z>]
- 195.5, 85.2, 2.4
- 192.0, 82.5, 2.5
- 198.5, 88.0, 2.2
- 215.0, 105.0, 0.6
- 218.5, 108.2, 0.55
- 212.0, 102.5, 0.7
```

> 6 个三变量观测点；温度—压力呈正相关，但收缩率在高温高压组骤降（可据此发现工艺窗口）。
