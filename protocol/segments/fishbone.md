# fishbone (因果分析/鱼骨图) 协议切片

## 1. 专家灵魂 (The Soul)

### 石川图 (Ishikawa) 因果分析原理

鱼骨图，又称因果图，是整理**问题与原因**之间关系的一种极佳工具。鱼头是待分析的问题（写进 `Title:`），大骨是原因分类，中骨/小骨是逐级下钻的原因。

#### 1. 5M1E 模型（制造业）

- **人 (Man)**：操作员、技能、意识。
- **机 (Machine)**：设备稳定性、精度、润滑。
- **料 (Material)**：原材料、品质、规格。
- **法 (Method)**：工艺标准、操作流程。
- **环 (Environment)**：温湿度、照明、噪音。
- **测 (Measurement)**：测量工具、抽样方法。

#### 2. 4P 模型（服务业 / 管理）

- **策略 (Policies)**：规章制度、管理流程。
- **程序 (Procedures)**：具体作业步骤。
- **人员 (People)**：能力、态度、协作。
- **场所 (Plant)**：办公环境、系统工具。

> [!TIP]
> 鱼骨图的深度决定了解决问题的深度。推导出某个原因后，连续追问「为什么」(5 Whys)，直到找到可措施化的根因节点。

## 2. 语法血肉 (The Flesh)

### IQS-DSL v1 — fishbone (Tree)

| 语法 | 说明 | 示例 |
| :--- | :--- | :--- |
| `Title:` | 问题陈述（渲染为**鱼头**） 形如 `<文本>` **必填** | `Title: 售后投诉根因分析` |
| `Color[Root | RootText | Main | MainText | Bone | Line | Text | End]` | #HEX 颜色：鱼头底 / 鱼头字 / 大骨底 / 大骨字 / 主脊椎线 / 子因连接线 / 原因文字 / 末端骨 | `Color[Root]: #E74C3C` |
| `#:` | 一级分类（**大骨**）—— 本 kind 中 `#` 是**结构**而非注释 形如 `# <分类名>` **必填** | `# 人 (Man)` |
| `##:` | 二级原因（**中骨**） 形如 `## <原因>` | `## 调机参数设置不当` |
| `###:` | 三级原因（**小骨**） 形如 `### <原因>` | `### 保压压力过低` |

### 边界说明

- **`Title`**：写"问题"而非"原因"；一个图只分析一个问题。
- **`#`**：⚠️ **本 kind 是唯一把 `#` 用作层级结构的 kind**（body = Tree）。其余 kind 中 `#` 仅作历史兼容注释，不可用 `#` 建层级。
- **`###`**：可继续用 `####` 等更深层级（引擎支持多级嵌套），但超过四级会显著压缩可读性。

### 反例（错 → 对）

- 错：`- 人 (Man)\n  - 调机参数设置不当`
  对：`# 人 (Man)\n## 调机参数设置不当`
  因：鱼骨图的层级必须用 `#` / `##` / `###` 表达；`-` 列表不会被解析为骨。
- 错：`Item: g1, 人 (Man), root`
  对：`# 人 (Man)`
  因：`Item:` 是**亲和图**（ItemTree）的录入方式；鱼骨图用 `#` 树。两者不可混用。
- 错：`# 调机参数设置不当   （把原因写成大骨，而问题无处安放）`
  对：`Title: 注塑件表面缩水故障分析\n# 人 (Man)\n## 调机参数设置不当`
  因：`Title:` 承载"问题"（鱼头），`#` 只能承载原因分类；不要把原因提到大骨层。
- 错：````dsl\nTitle: xxx\n````
  对：`Title: xxx`
  因：禁止 Markdown 代码围栏 —— 只输出纯文本 DSL。
- 错：`{"Title": "xxx"}`
  对：`Title: xxx`
  因：`dsl` 必须是纯文本字符串，不是 JSON 对象。
- 错：`这是根据您的需求生成的图表：\nTitle: xxx`
  对：`Title: xxx`
  因：禁止解释性前后缀。

## 3. 官方示例 (The Seed)

### 场景：注塑件表面缩水故障分析

```dsl
Title: 注塑件表面缩水故障分析
Color[Root]: #E74C3C
Color[RootText]: #ffffff
Color[Main]: #0D5E42
Color[MainText]: #ffffff
Color[Bone]: #475569
Color[Line]: rgba(13,94,66,0.18)
Color[Text]: #1A2428

# 人 (Man)
## 调机参数设置不当
### 保压压力过低
### 保压时间不足
## 巡检意识淡薄

# 机 (Machine)
## 料筒加热温度偏移
## 模具冷却水道阻塞
### 冷却水流量不足

# 料 (Material)
## 材料缩水率不均匀
## 回料比例过高

# 法 (Method)
## 工艺标准不完善
## 注射速度过快
```

> 5M1E 中取 4 个大骨（人/机/料/法），大小骨共 12 个原因节点。
