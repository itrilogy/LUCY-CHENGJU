### 功能描述（登记表「软件用途/功能」可精简粘贴）

本软件是面向质量管理（QC）小组活动的 Web 端图表工作站。用户可通过领域特定语言（IQS-DSL）或自然语言（经大模型推理生成 DSL）描述业务数据与逻辑，系统自动解析并渲染鱼骨图、排列图、直方图、控制图、散点图、雷达图、关联图、矢线图、PDPC、矩阵图、图矩阵、亲和图、基础统计图等专业图表；支持样式配置、画布交互、多格式导出及与质量管理 PDCA 流程配套的分析展示。系统遵循质量管理小组活动相关准则，内置 SPC 判异、累计贡献、过程能力等专业计算逻辑。

2. IQS-DSL 解析与校验模块

4. 图表编辑器与样式配置模块

| **主要功能** | 见下节 |

### 功能描述

本软件基于模型上下文协议（Model Context Protocol, MCP），向 AI 助手与自动化代理提供质量管理图表的标准化工具调用能力。服务支持 Stdio 与 SSE 两种传输；对外声明精简工具清单与按需协议资源；接收纯文本 DSL 后，通过无头浏览器驱动前端引擎完成高清图表渲染，并以图片或 URL 形式返回结果。系统区分核心 QC 工具与类型外扩展工具，支持协议资源动态拼接与输入格式校验。

### 登记用功能模块列表

1. MCP 协议接入模块（Stdio / SSE）  
2. 工具清单与瘦声明模块  
3. 协议资源读取与拼接模块  
4. DSL 输入校验与错误回执模块  
5. 无头浏览器渲染调度模块  
6. 渲染结果存储与静态访问模块（SSE 模式）
