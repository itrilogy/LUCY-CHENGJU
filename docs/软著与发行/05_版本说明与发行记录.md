## 2. V3.5.3-ildr 发行说明（当前）

### 2.1 主要能力

- IQS-DSL **v1.1** 完整语法手册与注册表落盘  
- 13 类 CORE 原生图种 + Mermaid/VChart 救济  
- MCP 瘦声明、CORE/RELIEF 分层、双传输  
- Docker 多阶段构建与运行时配置注入  
- 品牌：IQS 产品标 + **官方实验室主 LOGO（LUXI LAB.svg）**  
- 软著与发行文档包（本目录）

### 2.2 兼容性

- Node 20+  
- 现代 Chromium 系浏览器  
- DSL：以 `docs/IQS_DSL_V1_MANUAL.md` 为准；旧手册仅历史参考  

### 2.3 已知限制

- AI 密钥默认可出现在浏览器配置中，**高安全场景需改为服务端代理**（加固项）  
- 无头渲染依赖本机/容器内浏览器，冷启动耗时高于常驻浏览器池方案  
- 部分 Editor 内嵌帮助文案可能滞后于 v1.1 手册  

### 2.4 发行包应包含

- 源代码或构建产物（按单位策略）  
- `README.md`、`COPYRIGHT.md`、`CHANGELOG.md`、`NOTICE.md`  
- `docs/软著与发行/**`  
- `docs/IQS_DSL_V1_MANUAL.md`  
- `.env.example`、`docker-compose.yml`、`Dockerfile`  
- `public/brand/**` 品牌文件
