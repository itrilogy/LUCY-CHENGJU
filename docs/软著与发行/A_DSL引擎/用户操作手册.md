## 1. 软件概述

### 1.1 软件用途

本软件用于质量管理活动中的专业图表编制与分析展示。用户通过图形界面或 **IQS-DSL** 文本描述业务数据，系统自动生成鱼骨图、排列图、控制图等图表，并支持导出。

### 1.2 运行环境

- 操作系统：Windows / macOS / Linux  
- 浏览器：Chrome、Edge 等现代浏览器  
- 部署后访问地址：默认 `http://localhost:5173`（以实际为准）  

### 1.3 角色说明

| 角色 | 典型操作 |
|:---|:---|
| 业务用户 | 选图、填数、调样式、导出 |
| 高级用户 | 直接编写 DSL、对接 AI 生成 |
| 管理员 | 部署、配置 API、备份 |

## 3. 界面总览

### 3.1 工作台（Dashboard）

- 展示产品标识与鹿溪联合实验室出品信息  
- 以卡片网格列出可用图种  
- 可调节网格列数、切换明暗主题  
- 点击卡片进入对应图种工作区  

### 3.2 图种工作区布局

| 区域 | 功能 |
|:---|:---|
| 左侧边栏 | 返回工作台、当前图种编辑器（表单 / DSL / AI） |
| 顶部栏 | 当前图种名称、整理布局、导出 PNG/PDF |
| 中央画布 | 实时预览图表 |

### 3.3 品牌与版权标识

界面展示 IQS 产品标与实验室主 LOGO（官方鹿标），页脚含著作权单位信息。

## 4. 基本操作流程

### 4.1 选择图种

1. 打开工作台  
2. 根据 QC 阶段选择图种（如现状调查→排列图，过程稳定→控制图）  
3. 进入工作区  

### 4.2 编辑数据（三种方式）

**方式 A — 表单（手动）**  
在编辑器「手动」页签增删改数据项、样式。

**方式 B — DSL 文本**  
在「DSL」页签按语法编写；保存/解析后画布更新。  
完整语法见：`docs/IQS_DSL_V1_MANUAL.md`。

**方式 C — AI 生成**  
在「AI」页签用自然语言描述需求，生成 DSL 后可再手工修改。  
需管理员预置可用的模型 API。

### 4.3 导出

1. 点击「导出 PNG」按提示设置透明/倍率等  
2. 或导出「有底 PDF / 透明 PDF」  
3. 文件保存至本机下载目录  

### 4.4 返回工作台

点击侧栏产品标识或标题区域返回 Dashboard。

## 5. 主要图种操作说明

> 下列为操作要点；细节与字段说明见 `docs/USER_MANUAL_*.md` 与 DSL 手册。

### 5.1 鱼骨图（因果）

- 用途：根因分析、5M1E  
- 数据：大骨/中骨/小骨层级  
- DSL：`#` / `##` / `###` 层级（**仅本图种用 # 作结构**）  

### 5.2 排列图（帕累托）

- 用途：关键少数、ABC  
- 数据：项目 + 频数；系统自动排序与累计  

### 5.3 直方图

- 用途：分布、规格限、过程能力观察  
- 数据：原始测量值列表；可设 USL/LSL/Target  

### 5.4 控制图（SPC）

- 用途：过程稳定性、判异  
- 必设：图种类型 Type、子组 Size（视类型）、序列数据  
- 可选：Nelson / Western-Electric 规则  

### 5.5 散点图

- 用途：相关与回归  
- 数据：X,Y 或 X,Y,Z 点列  

### 5.6 雷达图

- 用途：多维对比  
- 数据：多个 Axis + Series 数值  

### 5.7 关联图

- 用途：多重因果  
- 数据：Node + Rel 有向关系  

### 5.8 矢线图

- 用途：进度与关键路径  
- 数据：Event + 带工期箭线；支持虚活动  

### 5.9 PDPC

- 用途：预案与对策分支  
- 数据：Group/Item + OK/NG 连线  

### 5.10 矩阵图 / 图矩阵

- 矩阵图：多对多符号关系与计分  
- 图矩阵：多变量散点矩阵、平滑与分层  

### 5.11 亲和图

- 用途：KJ 法归类  
- 数据：**必须** `Item: id, label, parent`（不要用鱼骨式 # 树）  

### 5.12 基础图

- 用途：柱/线/饼等通用统计  
- 数据：Dataset 行  

### 5.13 扩展（Mermaid / VChart）

- 类型外需求使用；**不宜替代**正式 QC 成果中的专业统计图

## 6. DSL 使用入门

### 6.1 最小示例（排列图）

```dsl
Title: 售后问题排列图
ShowValues: true

- 破损: 40
- 延误: 25
- 错发: 10
```

### 6.2 注释规则

- 推荐：`// 注释`  
- `# 标题` **仅鱼骨图**表示层级；其它图中 `#` 可能被忽略  

### 6.3 详细语法

请阅读：**`docs/IQS_DSL_V1_MANUAL.md`**

## 7. 常见问题

| 现象 | 处理 |
|:---|:---|
| 页面打不开 | 检查服务是否启动、端口是否被占用（见终端 Local 地址） |
| AI 无响应 | 检查 `.env` / `config` 中 API_KEY 与网络 |
| 亲和图空白 | 改用 `Item:` 语法，勿用 `#` 建树 |
| 导出模糊 | 提高导出倍率 |
| 控制图不像 SPC | 检查 Type、Size、[series] 数据块 |

更多：`docs/TROUBLESHOOTING.md`
