## 1. 引言

### 1.1 编写目的

说明本软件的总体设计、模块划分、关键算法与接口，供软件著作权登记鉴别、内部维护及发行交付使用。

### 1.2 项目背景

质量管理小组活动需大量专业图表（排列图、控制图、鱼骨图等）。传统拖拽绘图存在风格不一致、修改成本高、难以与 AI 协作等问题。本系统以 **领域特定语言（IQS-DSL）** 为契约，结合 Web 渲染引擎与可选大模型推理，实现「描述即图表」。

### 1.3 参考资料

- T/CAQ 10201 质量管理小组活动相关准则（业务遵循）  
- `docs/IQS_DSL_V1_MANUAL.md` IQS-DSL v1.1 语法手册  
- `docs/IQS_DSL_V1_SPEC.md` 语言架构规范  
- `protocol/governance.md` 协议权威序  
- Model Context Protocol 公开规范（与 MCP 服务协同时）

### 1.4 术语

## 2. 系统概述

### 2.1 目标

1. 提供统一的 QC 图表编辑与预览工作站；  
2. 以 IQS-DSL 固化专业语义，保证可复现、可审计；  
3. 支持 AI 辅助生成 DSL；  
4. 支持多格式导出及无头渲染桥接（供 MCP 服务调用）。

### 2.2 运行环境

| 层级 | 要求 |
|:---|:---|
| 客户端 | 现代浏览器（Chromium 内核推荐） |
| 服务端（开发/预览） | Node.js 20+ · Vite 6 |
| 可选 AI | OpenAI 兼容 Chat Completions API（如 DeepSeek） |
| 部署 | 裸机 `npm` 或 Docker Compose |

### 2.3 总体架构

```text
┌─────────────────────────────────────────────┐
│  表现层  React 19 + Tailwind（工作台 UI）      │
├─────────────────────────────────────────────┤
│  应用层  工具路由 / 状态 / 导出 / 主题         │
├─────────────────────────────────────────────┤
│  语言层  IQS-DSL 解析（parse*DSL）+ 注册表    │
│          dsl/kinds.json · Shell/Body 代数     │
├──────────────────┬──────────────────────────┤
│  渲染层·统计图    │  渲染层·逻辑图              │
│  ECharts 等       │  G6 / Canvas / Mermaid 等   │
├──────────────────┴──────────────────────────┤
│  智能层  aiService（配置驱动模型调用）         │
├─────────────────────────────────────────────┤
│  桥接层  headless 模式 · captureIQSChart      │
└─────────────────────────────────────────────┘
```

### 2.4 设计原则

1. **数据与表现分离**：DSL 描述业务，引擎负责布局与绘制。  
2. **核心与救济分离**：专业 QC 图走 CORE；Mermaid/VChart 为 RELIEF。  
3. **单一语言权威**：语法以 IQS-DSL v1 手册 + 解析器为准。  
4. **可导出、可无头**：统一 `BaseDiagramRef` 导出接口。

## 3. 功能模块设计

### 3.1 工作台与导航

- 入口：`App.tsx`、`DashboardView.tsx`、`Workspace`  
- 功能：图种选择网格、主题切换、关于信息、品牌展示  
- 输出：当前 `QCToolType` 驱动侧栏编辑器与画布组件

### 3.2 IQS-DSL 语言与解析

- 注册表：`dsl/kinds.json`、`dsl/registry.ts`  
- Shell 工具：`dsl/shell.ts`（注释、Title、Color 等行分类）  
- 分图解析：`components/*Editor.tsx` 中 `parse*DSL`  
- 图种（CORE 示例）：fishbone、pareto、histogram、control、scatter、radar、relation、arrow、pdpc、matrix、matrixPlot、affinity、basic  

**语言三层结构：**

```text
Shell（Title / Color / Font / Show* / 注释）
  + Directives（Type / Layout / USL … 按 kind 白名单）
  + Body（Tree | Pairs | Series | Graph | …）
```

### 3.3 图表渲染

| 类型簇 | 技术 | 代表图种 |
|:---|:---|:---|
| 统计图 | ECharts 等 | 排列图、直方图、散点、雷达、基础图 |
| 逻辑图 | G6 / 自研 Canvas | 鱼骨、关联、矩阵、矢线、PDPC、亲和 |
| 救济 | Mermaid / VChart | 流程、桑基等类型外需求 |

统一导出接口 `BaseDiagramRef`：`getDataURL` / `exportPNG` / `exportPDF`。

### 3.4 编辑器

每种 CORE 图种对应 `*Editor` 组件，提供：

- 表单编辑  
- DSL 文本编辑与即时解析  
- AI 生成入口（调用 `services/aiService.ts`）  
- 内嵌帮助（逐步与 v1 手册对齐）

### 3.5 AI 辅助生成

- 配置：`public/config.json` 多 profile + 运行时 `window.APP_CONFIG`  
- 流程：意图/子类型确定 → 拼接 master + 专项协议 → 调用 Chat API → 清洗围栏 → 回填 DSL  
- 约束：输出纯文本 DSL，禁止 JSON 对象包裹

### 3.6 导出与无头桥接

- 交互导出：PNG / PDF  
- Headless：`?mode=headless&type=&dsl=`  
- 全局桥：`window.captureIQSChart`、`window.IQS_READY`  
- 供 MCP Server 无头调用，实现「服务侧渲染、前端引擎计算」

### 3.7 配置与品牌

- 运行时配置：`public/config.js`（Docker 入口注入）  
- 品牌：`public/favicon.svg`、`public/brand/*`  
- 实验室主标：官方 `LUXI LAB.svg` 同步件

## 4. 关键算法与专业逻辑

### 4.1 控制图（SPC）

- 支持 I-MR、X-bar-R、X-bar-S、P/NP、C/U 等  
- SPC 常数表、控制限计算  
- Nelson / Western-Electric 判异规则可选  

实现：`ControlChart.tsx` + `parseControlDSL`

### 4.2 排列图

- 强制降序  
- 累计百分比  
- 80% 参考线与 ABC 语义  

### 4.3 直方图

- 分箱（含 Sturges 自动）  
- 正态曲线  
- USL/LSL/Target 与过程能力相关展示  

### 4.4 矢线图

- CPM 关键路径计算  
- 虚活动 `..>`  

### 4.5 矩阵图

- L/T/Y/X/C 几何  
- 强弱符号与权重计分

## 5. 接口设计

### 5.1 外部配置接口

| 配置项 | 来源 | 说明 |
|:---|:---|:---|
| API_KEY | 环境变量 / APP_CONFIG | 模型调用密钥 |
| AI_ACTIVE_PROFILE | 同上 | 激活模型配置名 |
| config.json | public | endpoint、model 列表 |

### 5.2 无头 URL 接口

```text
GET /?mode=headless&type={kind}&dsl={urlencoded}&theme=light
```

### 5.3 与 MCP 的协作边界

| 边界 | 引擎职责 | MCP 职责 |
|:---|:---|:---|
| 协议 | 解析 DSL、绘制、导出 | 工具声明、调度浏览器、回传图片 |
| 部署 | 提供 Web 服务（如 12000） | 连接 BASE_URL 进行渲染 |

## 6. 数据设计

### 6.1 运行时状态

以 React 状态保存各图种 `data` + `styles` + 部分原始 `dsl` 字符串；无强制后端数据库。

### 6.2 持久化

当前版本以会话内状态与用户导出文件为主；DSL 文本可作为交换格式存档。

### 6.3 交换格式

**IQS-DSL 纯文本** 为标准交换格式（见语法手册）。

## 7. 安全设计
