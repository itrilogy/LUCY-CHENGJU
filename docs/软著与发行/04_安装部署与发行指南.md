# 安装部署与发行指南

| 项 | 内容 |
|:---|:---|
| 产品 | Intelligent QC Studio（IQS）V3.5.3-ildr |
| 含组件 | Web 图表引擎 + MCP Server |
| 日期 | 2026-08-11 |

---

## 1. 发行形态

| 形态 | 适用 | 说明 |
|:---|:---|:---|
| **源码交付** | 内网二次开发 | 交付仓库或源码包 + 本文档 |
| **Docker 镜像/Compose** | 标准生产试运行 | 一键起 Web + MCP |
| **分服务部署** | 高可用扩展 | 前端静态/预览 与 MCP 分主机 |

---

## 2. 环境要求

| 组件 | 最低建议 |
|:---|:---|
| CPU / 内存 | 2 核 / 8GB（含无头渲染时建议 4 核 / 8GB+） |
| 磁盘 | 2GB+（含 node_modules 与 Chromium 时更多） |
| Node.js | **20.x 或以上**（开发验证用 20/22/26） |
| 浏览器 | Chrome / Edge 最近两个大版本 |
| 网络 | 若启用公网大模型 API，需出站 HTTPS |

---

## 3. 源码安装（开发 / 内网）

### 3.1 获取软件

按单位规定自 Git 或发行介质解压至目标目录。

### 3.2 安装依赖

```bash
cd smart-qc-studio
npm install
cd mcp-server && npm install && cd ..
```

若 `npm install` 网络中断，可重试或配置内部 npm 源。

### 3.3 配置

```bash
cp .env.example .env
```

编辑 `.env`：

| 变量 | 说明 |
|:---|:---|
| API_KEY | 大模型 API 密钥（仅当使用 AI 功能） |
| AI_ACTIVE_PROFILE | 对应 `public/config.json` 中 profile 名 |

按需修改 `public/config.json` 中 endpoint 与 model。

### 3.4 启动 Web 引擎

```bash
npm run validate:dsl   # 可选，语法/清单校验
npm run dev            # 开发：默认 http://localhost:5173
```

若提示 **Port 5173 is in use**：

- 使用终端给出的备用端口（如 5174），或  
- `lsof -i :5173` 后结束旧进程再启。

生产构建预览：

```bash
npm run build
npm run preview -- --host 0.0.0.0 --port 5173
```

### 3.5 启动 MCP（可选）

```bash
# 先保证 Web 可访问
export IQS_BASE_URL=http://localhost:5173
npm run mcp:stdio    # 本地代理
npm run mcp:sse      # HTTP :3000
```

## 4. Docker 部署

### 4.1 准备

```bash
cp .env.example .env
# 填写 API_KEY 等
```

### 4.2 启动

```bash
docker compose up -d --build
```

### 4.3 端口

| 端口 | 服务 |
|:---|:---|
| 5173 | Web（Vite preview） |
| 3000 | MCP SSE |

### 4.4 入口脚本行为

`docker-entrypoint.sh` 在 `dist/config.js` 注入运行时 `API_KEY` / `AI_ACTIVE_PROFILE`，再启动 Web 与 MCP。

### 4.5 健康检查（手工）

1. 浏览器打开 `http://<主机>:5173` 见工作台  
2. 任选图种，默认数据可渲染  
3. （可选）MCP 客户端连接 `:3000/sse` 调用 `render_pareto`  

---

## 5. 配置项一览

| 配置 | 位置 | 说明 |
|:---|:---|:---|
| AI Profile | public/config.json | endpoint、model |
| 运行时密钥 | .env / dist/config.js | 勿提交真实密钥 |
| MCP 工具 | mcp-server/mcp_tools.json | 与 public 同步 |
| 前端基址 | IQS_BASE_URL | MCP 无头打开地址 |

同步工具定义：

```bash
npm run sync-tools
```

---

## 6. 升级

1. 备份 `.env` 与自定义 `config.json`  
2. 替换发行包或拉取新版本  
3. `npm install` / 重建镜像  
4. 执行 `npm run validate:dsl`  
5. 按 `05_版本说明与发行记录.md` 做回归  

---

## 7. 卸载

- 源码：停止进程，删除目录即可  
- Docker：`docker compose down`，按需 `docker rmi`  
- 注意删除含密钥的 `.env`
