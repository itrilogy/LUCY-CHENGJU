## 1. 软件概述

### 1.1 用途

本软件以 **MCP（Model Context Protocol）** 方式，向 AI 助手提供「生成质量管理专业图表」的工具调用能力。客户端传入 **IQS-DSL 纯文本**，服务调度无头浏览器调用 IQS 图表引擎渲染，并返回图片或访问链接。

### 1.2 运行环境

- Node.js 22+  
- 已启动的 IQS 前端（默认 `http://localhost:12000`）  
- Chromium/Chrome（供 Puppeteer）  
- 可选：Docker 一体化部署  

### 1.3 与图表引擎的关系

| 组件 | 角色 |
|:---|:---|
| 本 MCP 服务 | 协议接入、工具声明、渲染调度 |
| IQS 图表引擎 | DSL 解析、专业绘图、导出 |

二者可同机部署，也可分容器部署（需网络可达）。

## 2. 安装与启动

### 2.1 依赖准备

```bash
# 工程根目录
npm install
cd mcp-server && npm install && cd ..
```

确保前端可访问：

```bash
npm run dev
# 或生产预览 / Docker
```

### 2.2 Stdio 模式（本地 AI 客户端）

```bash
npm run mcp:stdio
# 等价：node mcp-server/index.js
```

在 Claude Desktop / 兼容客户端中配置启动命令指向上述进程。

### 2.3 SSE 模式（远程 HTTP）

```bash
npm run mcp:sse
# 默认端口 12001
```

客户端连接：`http://<主机>:12001/sse`  
渲染图访问：`http://<主机>:12001/renders/...`（若开启落盘）

### 2.4 环境变量

| 变量 | 说明 | 默认 |
|:---|:---|:---|
| IQS_BASE_URL | 前端引擎地址 | http://localhost:12000 |
| PORT | SSE 端口 | 12001 |
| IQS_SERVER_PUBLIC_URL | 对外访问前缀（生成图片 URL） | 自动探测 |

Docker 场景见发行指南。

## 3. 功能说明

### 3.1 列出工具

客户端调用 MCP `ListTools` 后，将看到一系列 `render_*` 工具，例如：

- `render_control`、`render_pareto`、`render_fishbone`…（**CORE**）  
- `render_mermaid_*`、`render_vchart_*`（**RELIEF**）  

描述中带有 `[CORE]` / `[RELIEF]` 及 `read: protocol://segments/...` 提示。

### 3.2 阅读协议资源（推荐）

生成复杂 DSL 前，先 `ReadResource`：

| 资源 | 用途 |
|:---|:---|
| protocol://dsl/v1 | 语言红线摘要 |
| protocol://governance | 核心/救济分层 |
| protocol://segments/iqs_native/control | 控制图完整语法与示例 |

### 3.3 调用渲染工具

**参数：**

| 参数 | 类型 | 必填 | 说明 |
|:---|:---|:---:|:---|
| dsl | string | 是 | **纯文本** IQS-DSL 或救济方言 |
| width | number | 否 | 默认 1200 |
| height | number | 否 | 默认 800 |

**正确示例（控制图片段）：**

```text
Title: 示例控制图
Type: I-MR
Rules: Nelson

[series]: 测量值
12.0, 12.1, 11.9, 12.2, 12.0
[/series]
```

**错误示例：**

- 传入 JSON 对象而非字符串  
- 使用 Markdown 代码围栏包裹且未清洗  
- 前端引擎未启动导致超时  

### 3.4 返回结果

| 模式 | 典型返回 |
|:---|:---|
| Stdio | 图片二进制/Base64（MCP image 内容） |
| SSE | 文本中的图片 Markdown 链接（renders 目录） |

## 4. 工具选用建议

| 需求 | 建议工具族 |
|:---|:---|
| QC 成果专业图 | `[CORE] render_*` Native |
| 流程图/时序 | mermaid 救济 |
| 桑基等复杂信息图 | vchart 救济 |

**禁止**用救济工具冒充 SPC/排列图等终稿专业统计图。

完整 DSL 语法：引擎侧 `docs/IQS_DSL_V1_MANUAL.md`。

---

## 5. 运维与排障

| 现象 | 处理 |
|:---|:---|
| 渲染超时 | 检查 IQS_BASE_URL；确认前端 headless 可打开 |
| 空白图 | 检查 type 与 DSL 是否匹配；看浏览器控制台 |
| 找不到 Chrome | 安装 Chrome/Chromium 或配置 Puppeteer 路径 |
| 端口冲突 | 修改 PORT 或释放占用 |
| 工具过多上下文爆炸 | 确认使用当前瘦声明版本；按需 read resource |

---

## 6. 安全建议

1. 勿将 SSE 端口无鉴权暴露公网  
2. 生产使用反向代理与访问控制  
3. 容器内再启用受限 Chromium 参数
