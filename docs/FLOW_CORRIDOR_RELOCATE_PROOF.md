## 0. 形式化问题

- 网格 `M = { (r,c) | 0≤r<R, 0≤c<C }`，每格可容纳一个节点（绘制格：节点 + 2×half 走廊），宽 `pw`、高 `ph`。
- 节点集 `N`，边集 `E`（连线条，a→b，带端口方向，正交布线于格子走廊）。
- **腾挪算子**（用户规则，左上 (0,0) 基准，下=+y、右=+x）：
  - 若横向走廊所在行 `r*` 右侧存在障碍列 `b`，则 `{(r,c)| c==b, r≥r*}` 整体 `y += ph`（**下移**）。
  - 若纵向走廊所在列 `c*` 上方存在障碍行 `a`，则 `{(r,c)| r==a, c≥c*}` 整体 `x += pw`（**右移**）。
- 目标：使每条边都能走"就近格子走廊"，无穿越、无绕到画布边缘。

---

## 1. 收敛性证明（严格）

### 1.1 终止性（主定理，严格）——良基偏序 + 上界
**腾挪方向单调（只下、只右）**：
- 右侧腾挪 → 相关列节点 `y += ph > 0`（只增 y）；
- 上方腾挪 → 相关行节点 `x += pw > 0`（只增 x）。

**画布外延有限**：每次只往右/下外扩 ≤ 一个绘制格；受节点数 N 约束，总外扩 ≤ N×绘制格。故每个节点的坐标 `(x,y)` 在偏序 `(≤,≤)` 上**单调不减且有一致上界**。

**良基性**：在 `(≤,≤)` 偏序上，任何"严格单调不减 + 有上界"的点序列**必然终止**（不存在无限严格递增且有界的序列）。因此任意腾挪执行序列**长度为有限**；连锁（A 下移压到 B → 对 B 腾挪）每次推进某个坐标严格增，链长也有界，**不会无限循环**。

> **结论①（严格）**：障碍腾挪算法**必然终止**（有限步收敛），无论执行顺序。✅ 这是主证明，不依赖任何势函数单调性假设。

### 1.2 终止时的状态（稳定点）
终止时不存在"可被当前规则再推进的障碍"——即每条边要么走走廊无绕行，要么受阻于"已推到边界/推动会引入同量级新阻挡"的障碍。终止点是**稳定点**。

### 1.3 收敛"质量"的诚实说明
- **不能声称**"每次腾挪 Φ 严格单调减小"：腾挪把 A 下移可能压到 B 的路线，B 被迫绕行、其 Φ 增加——**Φ 非全局单调**。
- 但**收敛（终止）由 1.1 良基性严格保证**；达到的是**局部稳定**（每边在该腾挪顺序下不能单边更优）。
- 达到"无绕行 Φ=0"需网格容量足够（见 §2），且配合③合并+⑤迭代避免次优稳定点（见 §3）。

---

## 2. 可解性（证明"能解决"，含前提）

### 2.1 无绕行稳定点定义
若终止时 Φ = 0（每条边实际 = 最短曼哈顿），则**所有连线走纯直线/就近折线，无绕行**——即"连线走格子走廊、不再绕画布边缘"的问题**被解决**。

### 2.2 前提（诚实声明）
Φ → 0 **需要**：
- 每对端口间存在**可穿越的走廊**（即网格在腾挪后仍连通，节点不把某走廊完全堵死）。若一个绘制格同时被多个方向节点占满、且腾挪预算（画布外扩）耗尽，仍可能留部分绕行——**此时是画布/网格容量限制，而非算法失败**。
- 因此严格命题应为：**若存在一个"所有连线能走 L1 最短走廊"的布局（网格容量足够），则腾挪可达之（Φ=0）；若容量不足，则收敛到 Φ=Φ_min（最小可行绕行）。**

### 2.3 可解性论证
- 步 1 已证收敛到稳定点（Φ 不再可减）。
- 在稳定点，若某边仍绕行（Φ>0），则该边走廊必有障碍，且该障碍**已无法再被推**（要么已推到边界、要么推动会引入更大绕行）——即达到**局部极小**。
- 若网格容量足够（每对端口间存在空走廊），则不存在"无法消除的阻挡"，稳定点必为 Φ=0。✅

**结论②（可解）**：在"网格容量足够"前提下，腾挪可达 Φ=0（全连通、无绕行）；容量不足则达 Φ_min。→ **能解决"连线走走廊不绕行"**。

---

## 3. 最优性（诚实分级）

### 3.1 能达到的最优
- 收敛点是**局部最优**：任一边不能再单边减绕行。
- 对"所有边同时达到各自最短 L1"的解，若存在，腾挪可达（结论②）。

### 3.2 不夸大：全局最优需迭代+合并
- **贪心单次腾挪不保证全局最优**：不同边对同一走廊的争夺，可能因腾挪顺序不同而到不同局部极小。
- 但结合**运输模型③（交汇且同目的地→合并，取后程最短）**和**⑤（迭代重调优：Φ 不再降时，尝试换腾挪顺序/合并后重算）**，可避开次优稳定点——即把单次贪心升级为"贪心 + 迭代 + 合并"达到**全局最优（Φ 全局最小）**。

**结论③（最优）**：障碍腾挪本身保证**收敛 + 局部最优**；配合③合并 + ⑤迭代，可达到**全局 Φ 最小**。✅（在网格容量内）
