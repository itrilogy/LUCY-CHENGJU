## 1. 决策变量与统一目标泛函

布局与连线统一为一个组合优化问题。决策变量：

- 每个节点 `u` 的槽位 `(gx_u, gy_u)`（含对角扩展格，界内 32/64）；
- 每条边 `e` 的端口对 `(sp_e, tp_e) ∈ {T,B,L,R}²`；
- 每条边 `e` 的正交路径 `π_e`（通道网格上，同伦类固定）。

**统一泛函**（把现有分散权值统一度量）：

$$\Phi = \sum_e \left( w_B \cdot \mathrm{bends}(\pi_e) + w_L \cdot \mathrm{len}(\pi_e) + w_X \cdot \mathrm{overlap}(\pi_e) \right) + \sum_u w_S \cdot \mathrm{shift}(u)$$

与现有代码的对应：`computeCost` 已含 `bends*100 + len*0.01`；端口势能 `E = 100·bends + 50·blocked + 20·reuseOut + 5·reuseIn − 35·alignment` 已在 `solveAlgebraicPorts`。**缺口**：`w_S·shift`（理论全序中的 `C_shift1 = 150`）无处安放——布局/连线两阶段解耦后，连线层感知不到位移成本。本框架 §4 T2 用「守护位移算子」把 150 项接回，闭合 `FLOW_ROUTING_ALGEBRAIC_THEORY.md` §3.2 的三折线上界松弛链路。

### A6 的三条配套性质

1. **良基性保持**：对角位移 `(gx+1, gy+1)` 在偏序 `(≤,≤)` 上仍严格单调递增 + 界内 → `FLOW_CORRIDOR_RELOCATE_PROOF.md` §1.1 收敛主定理**原样成立**，算子集扩展不动证明。
2. **支配引理 L0**：当且仅当水平与垂直两轴均受阻时，对角算子严格占优于「先 +x 再 +y」两次轴对齐位移（150 < 300）；单轴受阻时退化为单轴位移。
3. **几何对齐兼容**：节点仍严格居中于绘制格；`cellXY` 的 `nx = max(gx+1)` / `ny = max(gy+1)` 语义自动吸收对角格（③ 整行/整列统一扩展公理的直接推论），**连线引擎零改动**（连线本就走所在走廊，仍纯正交，绝无斜线）。

## 3. 两个结构性引理（解空间有限化）

### L1 正则化引理（canonicalization）

> 任意可行解都存在同伦类相同、Φ 不增的解，其所有拐点位于通道网格 `X_mesh ∪ Y_mesh` 上。

**证明义务与思路**：非网格拐点向最近网格线平移；障碍盒边界全在网格线上（A5），平移至与障碍相切之前不产生新碰撞；平移不增折弯、不减短长度。VLSI 正交布线的标准证据转移，适配本网格体系。

**作用**：无限连续解空间 → 有限离散空间，「最优解存在」得证，后续一切搜索/ILP 合法化。代码现状已满足吸附（`snapTo` / `computeGridChannels`），本引理是对现状的合法化证明。

### L2 同伦类枚举完备性

> `solveAlgebraicRoute` 的分级候选（直连→L→Z 局部走廊→3~4 弯→外侧走廊）覆盖了所有极小同伦类。

**证明义务与思路**：k 个障碍下，两端口间绕行拓扑类由「外侧四向 + 逐个内走廊穿越」生成；逐一对应现有候选表。若个别类缺失，改为系统化的网格可见图枚举（等价覆盖）。

**作用**：把「经验候选」升级为「完备候选」——配合 T1，单边求解从启发式升格为**可证精确**。

## 4. 四个定理

### T1 单边精确性

固定端口对与同伦类后，最小折弯/最短路径 = 状态图 `G' = 格点 × 4方向` 上的最短路（前进权 `w_L`、拐弯权 `w_B`，Dijkstra），多项式可解。**现状的分级候选是 T1 的手工同伦类枚举**，L2 补齐完备性后即等价。

### T2 守护位移单调收敛（对「腾挪 2→4 恶化回退」教训的数学化根治）

**守护位移算子**（guarded shift operator）：

- 执行位移前精确枚举受害边集 `S`（穿过被挪格 ±1 格走廊的边，可枚举）；
- 仅当 `ΔΦ = (受益边改善) − Σ_{e∈S}(恶化) ≤ −150` 时接受，否则回滚。

**定理**：每次接受的位移严格 `ΔΦ < 0`，且位移方向单调（含 A6 对角，仍只增不减）+ 界内 → 良基性 → **必然终止**；终止点不存在可接受的守护位移 = **位移邻域下的一阶局部最优**。

> 这把 `FLOW_CORRIDOR_RELOCATE_PROOF.md` §1.3 自认的「Φ 非全局单调、盲目腾挪可能连锁恶化（实测 2→4 条）」从工程教训升格为有护栏的定理：护栏不再是纪律，而是接受条件本身。

### T3 布线层 ILP 全局最优（给定布局）

布局槽位已定时，布线子问题 ILP 化：

- **变量**：端口选择 `p_{e,d} ∈ {0,1}`、通道线占用 `f_{e,g} ∈ {0,1}`、折弯计数 `b_e ∈ {0..3}`；
- **约束**：每节点一槽、WSAD（A1）、流守恒（路径性）、节点盒互斥（A4）、拐点吸附（A5）、折弯线性化；
- **目标**：min Φ。

业务规模（≤30 节点 / ≤40 边 / 通道线 ~120）→ 二元变量 10³–10⁴，CBC/Gurobi 秒级，**输出自带最优性证书（gap=0）**。用途：①离线黄金基线，量化在线启发式（T1 候选 + T2）的实测 gap；②兼作布局/布线回归基线（补「无可视化回归」短板）。

### T3'（目标定理，待证）受限泳道结构的全局最优

主干为单调递增链（沿流向逐列/逐行推进）、分支深度有界、无交叉回边的泳道图上，**贪心 + M8 合并 = 全局最优**。证明思路：主干边走廊选择相互独立、可交换（拟阵-like 结构），合并取后程最短保持单调。这是唯一值得攻「解析全局最优」的图类——恰是 665 体系文件审批图的主形态。

### T4 复杂度边界（诚实声明）

布局+布线全耦合的一般情形 NP-hard（正交 compaction 与 bend-minimal routing 耦合，VLSI 已证结论）。因此本框架**不承诺**一般情形的解析全局最优，以 §0 分层表为准。
