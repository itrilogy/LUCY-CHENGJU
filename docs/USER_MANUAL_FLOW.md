## 1. 软件概述

### 1.1 软件名称及版本
- **软件名称**：Smart QC Tools 工业级质量控制软件（IQS-DSL 企业体系文件流程引擎）
- **功能模块**：流程图 / 泳道图模块（Flow / BPMN 子集）

### 1.2 定位与用途
面向企业 **665 个体系文件中的程序文件（CX）** 等业务流程建模，回答"谁（泳道）× 做什么（活动）× 什么条件下走哪条路（网关）"三问。采用 **BPMN 2.0 语义子集** + **字典-索引（Dict-Index）范式**：一处定义、处处索引，既精炼又机器可校验。

### 1.3 核心特性
- **自研 SVG 渲染**：零第三方依赖，网格/走线/端口/避障逻辑完全确定性，可离线导出 PNG。
- **字典展开**：图上显示"信息中心"而非 `D[0]`，岗位显示"申请员"而非 `R[0]`。
- **高度整齐对齐**：XY 矩阵统一扩展、节点居中、行列齐平、连线走格子通道、长回边走外侧走廊。
- **六属性图例边栏**（`Attr active`）：岗位/SOP/风险度/时效/KPI/标记自动聚合。

## 2. 快速上手（30 秒出图）

```dsl
Title: 采购申请审批流程
Layout: H
Dict: D[信息中心,综合计划科,办公室]
Dict: P[申请阶段,审批阶段,执行阶段,归档阶段]
Dict: worker[提交采购申请,填写申请单,金额超过5000?,部门经理审批,...]
Lane from D[0,1,2] Layout H
Lane from P[0,1,2,3] Layout V
AxisX: 职能部门 Align C
AxisY: 推进阶段 Align C
W: w1: worker[0] Type[S] Location(D[0],P[0])
W: w2: worker[1] Location(D[0],P[0]) SOP(XX-CX-04) Role(R[0])
W: q1: worker[2] Type[?] Location(D[0],P[1])
   是 → #w4
   否 → #w5
   End
W: w4: worker[3] Location(D[1],P[1]) Role(R[1])
W: w5: worker[4] Location(D[0],P[2])
W: w6: worker[5] Location(D[2],P[2])
W: w7: worker[6] Type[E] Location(D[1],P[3])
w5 → #w6
w6 → #w7
```

输入到编辑器即得泳道审批图。

## 3. 语法层（DSL 参考）

### 3.1 数据层（字典）
| 语法 | 说明 |
|:---|:---|
| `Dict: D[信息中心,综合计划科,办公室]` | 部门（D 保留字） |
| `Dict: P[申请阶段,审批阶段,...]` | 阶段（P 保留字） |
| `Dict: R[申请员,部门经理,财务岗]` | 岗位（R 保留字） |
| `Dict: worker[动作...]` | 自定义字典（如动作/文件） |

### 3.2 结构层（泳道/轴/属性）
| 语法 | 说明 |
|:---|:---|
| `Lane from D[0,1,2] Layout H` | 横向泳道（行） |
| `Lane from P[0,1,2,3] Layout V` | 纵向泳道（列） |
| `AxisX: 职能部门 Align C` | X 轴坐标标题（C/L/R 对齐） |
| `AxisY: 推进阶段 Align C` | Y 轴坐标标题 |
| `Axis: 整图标题 AxisX` | 整图标题（AxisX 顶部 / AxisY 左侧竖向） |
| `Attr active [Role,SOP,Lv,Time]` | 激活六属性图例边栏 |
| `Color[Panel]: #f8fafc` | 面板/节点配色槽 |

### 3.3 节点（活动）
```
W: <id>: <标签> [Type[?]] [Location(D[i],P[j])] [属性(...)]
```
- 类型：`Type[S]`开始 · `Type[E]`结束 · `Type[T]`任务 · `Type[?]`判断 · `Type[+]`并行 · `Type[SUB]`子流程 · `Type[N]`标注 · `Type[DATA]`数据对象。
- 属性：`SOP(依据编号)` · `Role(R[k])`岗位 · `Lv(重要)`风险度 · `Time(24h)`时效 · `KPI(≤1‰)` · `M(标记)`。
- 坐标：`Location(D[信息中心],P[申请阶段])` 或索引 `Location(D[0],P[0])`；可省略（自动落格）。

### 3.4 分支（网关）与子流程
```dsl
W: q1: 金额超过5000? Type[?]
   是 → #w4
   否则 → #w5   # 否则 = 默认出口
   End
W: q2: 来料检验 Type[SUB] Location(D[0])
   W: s1: 复检 Type[S]
   W: s2: 可接收? Type[?]
      可接收 → #s3
      End
   W: s3: 入库
   End
```

### 3.5 连线
- 分支行：`是 → #id`、`否则 [c] → #id`（`[...]`为条件，`(名)`为出口名）。
- 显式边：`w5 → #w6`。
- 无标注时按声明顺序自动连（网关不出默认边）。

## 4. 关键概念与技巧

### 4.1 字典-索引展开
`Role(R[0])` 在图上显示为字典值"申请员"；`worker[0]` 显示为"提交采购申请"。修改 `Dict` 一处生效全图。

### 4.2 高度整齐对齐
网格按 `Lane from` 统一扩展：**整列宽=该列最大横向链长、整行高=该行最大纵向链长**，所有交叉格等分、节点严格居中。子流程内部 / 标注 / 数据对象**不占交叉格**（不撑歪泳道）。

### 4.3 走线通道化
同行端口优先左右、同列优先上下；拐点吸附行列边界；穿越节点时改走格子边界 Z 通道；长回边避障失败自动绕**画布外侧走廊**。起点贴节点边界（非固定长度）。

### 4.4 校验提示（§10 规则）
- 字典名唯一（D/P/R 保留字不可重复定义）。
- `Type[?/+]` 必须有分支出口；`否则`每节点至多一条。
- 分支/连线目标必须是可流转节点（不可指向 N/DATA）。
- 开始节点 ≥1、结束节点 ≥1；无孤立节点（入/出边不完整会报错）。
- `Role(R[k])` 越界、`Attr active` 非法键会报错。

## 6. 常见问题

| 现象 | 处理 |
|:---|:---|
| 某节点没出现 | 检查 `Location` 泳道索引是否越界、是否被维度清洗 |
| 连线穿了别的节点 | 已内置外侧走廊；若仍穿，检查是否 `Type[N]`/`DATA` 被误当连线目标 |
| 图例不显示 | 确认 `Attr active [Role,...]` 合法键且节点确实有对应属性 |
