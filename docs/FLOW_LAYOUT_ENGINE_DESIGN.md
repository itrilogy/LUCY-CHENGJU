## ① 流程绘制格（3×3 切分）

一个"流程绘制格" = 一个流程节点，切成 3×3 九小格（W=节点宽 / H=节点高）：

```
第一行： 0.5W×0.5H │ 1W×0.5H │ 0.5W×0.5H   ← 连线区
第二行： 0.5W×1H   │ 1W×1H   │ 0.5W×1H     ← 中心格 = 节点
第三行： 0.5W×0.5H │ 1W×0.5H │ 0.5W×0.5H   ← 连线区
```

- **中心格（2,2）= 1W×1H** 放节点，节点**严格居中**（`cx = 绘制格左缘 + 绘制格宽/2`，`cy = 绘制格上缘 + 绘制格高/2`）
- **四周 8 格 = 连线区**，比例 0.5，**连线从连线区中线出发**（距离节点图形边缘 `half/2`）
- **不填充连线区颜色**（绘制格周围无色块，仅节点自身图形着色）

## ② 泳道交叉格 X×Y

一个交叉格的绘制格数由格内节点的 V/H 链排决定：

| 交叉格节点数及排布 | X×Y |
|:---|:---|
| 1 节点 | 1×1 |
| 2 节点横向（默认/H） | 1×2 |
| 2 节点纵向（V） | 2×1 |
| 横纵都有（V/H 链交错） | X×Y |

多个节点 = **增补绘制格**（不挤压原格）。

## ③ 行列真实宽高（对齐，无扩展格）

- **每列宽** = 该列各交叉格"自身真实需要宽"的最大值（`needW = nx × (格内节点最大宽 + 2×half)`），**不被某格 nx 盲目拉满整列**
- **每行高** = 该行各交叉格"自身真实需要高"的最大值（`needH = ny × (节点最大高 + 2×half)`）
- **空列/空行** = 基础中心格宽高（BASE_W=100 / BASE_H=60），不拉大
- **每个交叉格（含空格）都画真实列宽×行高的矩形边框**，行列对齐可见
- **节点严格居中于其绘制格**（两侧连线区等宽），消除相邻节点的空隙/扩展格

## ④ W / H 确定

- W = 该列绘制格中心节点的**最大宽**；H = 该行绘制格中心节点的**最大高**
- 但**节点位置**以"绘制格宽 pw / 高 ph"居中（pw = 列宽/nx，ph = 行高/ny），**不按列最大 W 强行拉大**
- 各形状有**基础尺寸** `NODE_BASE`：task 120×44、subprocess 140×48、gateway 80×50、start/end 圆 r=22、annotation 120×36、data 100×36；文字自适应不低于基础

## ⑤ 节点放入 + 连线（最小最短）

1. 算行列真实宽高 → X×Y 网格
2. 节点严格居中于对应绘制格
3. 连线从**节点朝向目标侧的连线区中线**出发，直连目标朝向源侧的连线区中线：
   - 同行 → 水平直达（右/左）
   - 同列 → 垂直直达（上/下）
   - 异行异列 → L 型一次拐弯（不绕中介格子）

## ⑥ 连线避障（后续迭代）

- 当前实现"最小最短直连 + 异行一次拐弯"；**避障（同行下移→同列右移→扩格）尚未完整实现**，留待连线验收后再做
- 规划：遇阻碍块尝试下移/右移，移不动扩格一个单位（上限 3 单位，防死循环）

## ⑦ 画布

- 全页面绘制区（FlowDiagram.fitView 自适应容器一页展现 + pan/zoom）
- 无泳道：整画布 1 个大格（ROOT 占位，不显示标签）
- 单泳道横向：仅 H 轴；单泳道纵向：仅 V 轴（坐标匹配兼容单维 cell）
