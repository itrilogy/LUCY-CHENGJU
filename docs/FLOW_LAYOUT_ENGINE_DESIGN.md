# IQS-Flow 布局算法 v3（最终确认版）

> **状态**: 算法已全部确认，待实现为 flowToSVG 正式渲染器
> **关键**: 统一网格贯穿棋盘 + X×Y 交叉格切分 + 节点居中(1W×1H) + 四周0.5连线区 + 行列最大W/H + 确定性避障 + 全页面绘制区

---

## ① 网格单位

一个"流程绘制格" = 一个流程节点，内部切成 **3×3 九小格**（W=节点宽 / H=节点高）：

```
第一行： 0.5W×0.5H │ 1W×0.5H │ 0.5W×0.5H
第二行： 0.5W×1H   │ 1W×1H   │ 0.5W×1H
第三行： 0.5W×0.5H │ 1W×0.5H │ 0.5W×0.5H
```

- **中心格（2,2） = 1W×1H** = 放流程节点
- **四周 8 格 = 连线区**（上/下/左/右 + 四角），比例 0.5
- **连线区 = 节点绘制格（中心格）四周，取中线位置**——连线从四周 0.5 宽度连线区的**中线**出发

## ② 泳道交叉格 X×Y 切分

一个泳道交叉格（V泳道×H泳道）= 若干个流程绘制格横向/纵向拼成 X×Y 矩阵：

| 交叉格节点数 | X×Y |
|:---|:---|
| 1 节点 | 1×1 |
| 2 节点横向(H) | 1×2 |
| 2 节点纵向(V) | 2×1 |
| 横纵都有 | X×Y（横向1×X个 + 纵向1×Y个） |

多个节点 = **增补流程绘制格**（不挤压）。

## ③ 全局行列统一切分（对齐关键）

- **某 V泳道行高** = 该行内所有交叉格的最大**纵向堆叠数**（如某格 2 节点纵向 → 该行所有格 2 单元高）
- **某 H泳道列宽** = 该列内所有交叉格的最大**横向并排数**
- 单节点在统一网格中**只占一部分**，其余保留空格
- 空白交叉格 → 保留网格线、不填充

## ④ W / H 确定（中心格尺寸）

- **以流程绘制格为行看** → 该行中**节点形状高度最高的** → 决定**中心格行高 H**
- **以流程绘制格为列看** → 该列中**中心节点形状最宽的** → 决定**中心格列宽 W**
- W = 该列绘制格中心节点最宽者宽；H = 该行绘制格中心节点最高者高
- 中心格 = 1W×1H，四周 0.5 连线区随之确定

## ⑤ 节点放入 + 连线

1. 算格子排列（行列最大切分定行高列宽）→ X×Y 网格
2. 节点放对应绘制格中心（3×3 布局中心格）
3. 连线从节点四周 0.5 连线区**中线**出发，走网格通道

## ⑥ 确定性避障（补充确认）

连线遇阻时，**确定性顺序**：
1. **先试同行下移**（向下一行通道绕）
2. **不行试同列右移**（向下一列通道绕）
3. **都不行 → 扩格**（扩展该交叉水平/纵向一个单位）
4. 再有阻碍 → 继续此循环

> 防死循环：设最大扩展上限（每交叉格最多扩 3 单位），超限则连线直连 + 报 warning。

## ⑦ 画布约束

**鉴于画布大小问题，先从"一个全页面"作为绘制区**用于展现——先在一张全页面里呈现完整泳道图，不追求一次画超大图。

## 实现要点（flowToSVG）

- 统一网格线贯穿（gridStep = 0.5 单位）
- 列宽 = 该列最大横向切分 × 全单位；行高 = 该行最大纵向切分 × 全单位
- 每个交叉格内 X×Y 绘制格，节点放中心格，四周 0.5 连线区取中线
- 连线从参与连线区中线出发，按"同行下移→同列右移→扩格"避障
- **全页面绘制**：初始按容器尺寸缩放适应（fitView），一页展现
