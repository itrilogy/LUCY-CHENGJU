## 一、V/H 节点属性语义（用户确认）

**标注位置**: 节点行**尾部**，如 `W: w2: 填写申请单 Role(R[0]) V`

**含义**: 节点带 `V` → 与**上一个节点**纵向排列（排在其**下方**）；带 `H` → 与上一个节点横向排列（排在其**右侧**）。

**生效范围**（只在泳道格子的内部排版生效）:
| 泳道形态 | 格子 | V/H 作用 |
|:---|:---|:---|
| 无泳道 | 整个画布 = 一个大格子 | 节点在大格内按 V/H 链排 |
| 单维泳道 | 每条泳道 = 一个格子 | 格内节点按 V/H 排 |
| 双维泳道 | 行列交叉格 | 格内多节点按 V/H 排 |

**关键**: V/H 是**格内**的链式排布指令（一个格子里多个节点怎么摆），**不决定**泳道本身。泳道（无/单/双维）决定格子长什么样；V/H 决定格内节点怎么排。

## 二、Excel 表格范式（用户红线图）

**先排节点 → 再叠泳道划分 → 连线顺间隙**

1. **列 = 阶段（V lanes），行 = 部门（H lanes）**，每个节点定位到 `(行, 列)` 交叉格
2. **单元格自适应**：
   - 列宽 = max(该列格内节点横向可容纳宽) + padding
   - 行高 = max(该行格内节点纵向可容纳高) + padding
   - 一个格子可放**多个**节点，按格内各节点的 V/H 链式排列
3. **泳道划分**：有泳道 → 画泳道带边框 + 行列表头；无泳道 → 整个是 1 格，不画
4. **连线**：顺单元格间隙（行列通道），正交，端点贴节点边界

## 三、格内多节点 V/H 链式排布

一个泳道交叉格（如"信息中心 × 执行阶段"）内可堆叠多个节点：
```
格内示例（都带 V）：
  W: w5: 直接执行, V      ← 格内起点
  W: w6: 财务付款, V      ← 排 w5 下方
格内红框：从上到下 [直接执行] → [财务付款]
```

**格内节点链算法**：
- 格内节点按声明顺序遍历
- 第一个节点放格内起点
- 后续节点：带 `V` → 放当前链末节点**下方**（vCursor += 上节点高 + 间隙）；带 `H` → 放当前链末节点**右侧**（hCursor += 左节点宽 + 间隙）；无标注 → 延续上一方向
- 格子的尺寸 = 格内所有节点按链排布后的总包围盒（宽 = 横排最右边界，高 = 纵排最下边界），再 + padding

## 四、无泳道 / 单维泳道退化

- **无泳道**：整个画布 1 个大格，全部节点按 V/H 链排（或按默认顺序），不画边框
- **单维泳道**：每泳道 1 格，格内节点 V/H 排

## 五、可验证性

布局引擎核心输出确定性坐标（格子尺寸、节点居中位置、链排坐标），可用 node 断言：
- 单元格宽度自适应（长列宽、短列窄）
- 格内 V 链节点垂直堆叠、H 链水平并排
- 区间连线走间隙
