## ① 流程绘制格（3×3 切分）

一个"流程绘制格" = 一个流程节点，切成 3×3 九小格（W=节点宽 / H=节点高）：

```
第一行： 0.5W×0.5H │ 1W×0.5H │ 0.5W×0.5H   ← 连线区
第二行： 0.5W×1H   │ 1W×1H   │ 0.5W×1H     ← 中心格 = 节点
第三行： 0.5W×0.5H │ 1W×0.5H │ 0.5W×0.5H   ← 连线区
```

- **中心格（2,2）= 1W×1H** 放节点，节点**严格居中**（`cx = 绘制格左缘 + 绘制格宽/2`）
- **四周 8 格 = 连线区**，连线从连线区**中线**出发/抵达（距节点图形边缘 `half/2`），**首末段垂直于节点该边中点**
- **不填充连线区颜色**（绘制格周围无色块）

## ② 泳道交叉格 X×Y 切分

一个交叉格的绘制格数由格内节点 V/H 链排决定（**无标注默认纵向 V**）：

| 交叉格节点排布 | X×Y |
|:---|:---|
| 1 节点 | 1×1 |
| 2 节点纵向（默认/V） | 2×1 |
| 2 节点横向（H） | 1×2 |
| 节点带 **D 对角标识**（A6 算子） | 双向扩（gx+1 且 gy+1，行列 ny/nx 同时计入） |
| 横纵都有（V/H/D 链交错） | X×Y |

- 后续节点按其**自身 vh** 相对上一节点排布（V 纵向 / H 横向 / D 对角右下）；首节点恒居格内原点 (0,0)
- D 标识的数学地位与配套性质（良基性保持 / 支配引理 L0 / 几何对齐兼容）见 `FLOW_OPTIMALITY_FRAMEWORK.md` §2 A6
- 多个节点 = **增补绘制格**（不挤压）

## ③ 整列/整行统一扩展（XY 矩阵规范）

- **列宽 = 该列最大 nx ×（该列节点最大宽 + 2×half）**——该列所有交叉格按 nx_max 等分
- **行高 = 该行最大 ny ×（该行节点最大高 + 2×half）**——该行所有交叉格按 ny_max 等分
- 单节点格在宽列内占 1 个绘制格（居中），其余留空；**整条泳道统一扩展**
- 空列/空行用基础格（BASE_W=100 / BASE_H=60），不盲目拉大

## ④ W / H 确定

- W = 该列中心节点最大宽；H = 该行中心节点最大高
- 节点位置按"绘制格宽 pw/高 ph"居中，不按列最大 W 强行拉大
- 基础尺寸 `NODE_BASE`：task 120×44、subprocess 140×48、gateway 80×50、start/end 圆 r=22、annotation 120×36、data 100×36；文字自适应不低于基础
- 圆形节点（start/end）文字超宽时加**灰色差异底色板**（与节点色、字体色均差异）

## ⑤ 连线：两趟端口分配 + 最短路径

1. **第一趟（入口）**：入口端口按朝向源的最短方向选，`usedIn` 记录
2. **第二趟（出口）**：出口端口优先选"未被出入口占"的方向；全占用则复用最短朝向端口
   - 规则：**出入口可各自共用，但出入口之间不共用同一侧**
3. 走线正交：首段沿源端口法向（R/L 先横、T/B 先竖），末段沿目标端口法向；异行异列 = L 型一次拐弯，**去零长段与共线中间点**（不产生 U/n 形）
4. 条件分支**文本标签放在折线最长线段中点**（水平段在线上方、垂直段在线右侧）

## ⑥ 避障连线（确定性）

- 节点形状包围盒碰撞检测（Liang-Barsky 线段裁剪）
- 确定性避障顺序：**同行下移 → 同列右移 → 反向 → 扩格**，上限 3 轮防死循环
- 箭头抵目标节点边中点，不超出

## ⑦ 表头（格子化 + 默认居中）

- **流程图标题**：`Axis: <标题> AxisX`（默认）→ 顶部通栏；`Axis: <标题> AxisY` → **左侧竖向标题带**（旋转 -90°，宽度 = 字号+32，不横排超宽）
  - AxisY 标题带高度 = `titleH → gridBottom`（与列标签行 + X 轴泳道网格齐平，不含顶部 titleH 区，不多不少）
  - 标题内容优先级：`axes.page.title`（Axis:）> `Title:` 行
- **列标签（上表头）**：每列一格，泳道值居中；`AxisX` 标题在左上角格（水平）
- **行标签（左表头）**：每行一格，泳道值**旋转 -90°** 竖向排列；`AxisY` 标题在左上角格（水平）
- **左表头列宽**：按轴标题文字宽度略宽（`max(48, 文字宽+28)`），非固定值，也非 Y 泳道文字宽度
- 单维泳道/无泳道 ROOT 占位不显示标签

## ⑧ 画布与整理布局

- SVG 内部已渲染完整标题/表头 → **组件层不重复渲染标题**，不额外添加布局控件
- **整理布局（tidyLayout）**：App.tsx 的「整理布局」按钮调用 `diagramRef.tidyLayout()`，整体绘制内容**等比缩放居中，尽可能占据画布**（`tx=(cw-w)/2, ty=(ch-h)/2`，正值居中）
- **拖动平移**：`preventDefault` + `user-select:none` + `touch-action:none` + 阻止原生 drag；**平移软边界** clampView（留 10% 余量）避免拖出画布边缘白屏
- pan/zoom（滚轮以中心为锚缩放、拖拽平移）

## ⑨ 泳道边界线

- 列/行边界线 = **虚线-细线**（`stroke-dasharray="4 4"`、0.8px、浅灰 #94a3b8），避免与连线视觉重叠
- 网格最右/最下边界与末列/行格子完全对齐（gridRight/gridBottom），无出血缺口
