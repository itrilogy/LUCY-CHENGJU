## 0. 一句话

现行优化在**边**上搜 `(sp, tp)`，用折弯当目标，把「侧能不能既入又出」当成可买的软条件（网关还整段关掉）。
设计意图要求先给每个节点的四侧**染色**（UNUSED / IN / OUT），染色是硬可行域；折弯、朝向、槽位只在这个域里优化。

---

## 1. 优化问题（评估要件 → 决策变量）

对每个节点 `n`、每个方向 `d ∈ {T,B,L,R}`：

```
role(n, d) ∈ { UNUSED, IN, OUT }
```

硬约束（红线 = 公理 A1）：

```
不存在 d 使得 role(n,d) 同时被入边和出边使用
⇔  Dirs_in(n) ∩ Dirs_out(n) = ∅
```

同向复用（公理 A3，合法）：

```
|{ e : e.to = n, tp(e) = d }| ≥ 1  ⇒  role(n,d) = IN     （多条入边可共享 d）
|{ e : e.from = n, sp(e) = d }| ≥ 1  ⇒  role(n,d) = OUT   （多条出边可共享 d）
```

DOC 虚边（`d1`、`n1`）**算入边**，占 A1 名额，不得特判豁免。

字典序目标（实现里用加权和近似，但优先级必须不可颠倒）：

| 层 | 项 | 硬/软 | 权重建议 | 说明 |
|:--:|:--|:--:|--:|:--|
| 0 | A1 违规数 | **硬** | `∞`（skip，不进候选） | 不能被 0 折弯买掉 |
| 1 | 背向端口数 | 软 | 1000 | AUD-143，可降级 |
| 2 | 折弯（含 180° 回折） | 软 | 100 | 现行 `countBends` |
| 3 | 曼哈顿长 | 软 | 0.01 | 次关键字 |
| 4 | 同侧拥挤（k 条共点） | 软 | 1 | 有槽位后可降为 0 |

**禁止**：网关白名单、`relaxNodes` 把层 0 关掉、用「否则无解」换既入又出。canonical `p1` 的可行解已经存在：贪心 `IN=B×2, OUT=R×2`。

## 2. 三阶段算法（在现行管线上改，不换内核）

```
布局 computeExcelLayout          ← 不动（③ 扩展格 / CellOrder）
  ↓
① 侧染色  colorSides(n)         ← 新增，A1 的可行域
  ↓
② 边绑定  bindPorts(e | role)   ← 替换 optimizePorts 的「16 对穷举 + relax」
  ↓
③ 路径    solveRouteHybrid      ← 沿用（自身盒 / 回折 / 混合内核）
  ↓
④ 槽位    offsetSlots(n,d)      ← 新增，同向 k>1 时沿边错位（M1）
  ↓
渲染 端点 / 箭头 / 标签
```

### 2.1 阶段① 侧染色（每个节点独立，O(1)）

对节点 `n` 的入边集合 `Ein`、出边集合 `Eout`：

```
for d in {T,B,L,R}:
  demandIn[d]  = Σ_{e in Ein}  facing(e, tp=d)     # 法向迎来源则 1，否则 0
  demandOut[d] = Σ_{e in Eout} facing(e, sp=d)     # 法向朝目标则 1，否则 0

# 需要两种角色时，必须两侧以上；一侧不够就让朝向差的边改侧，绝不让同一侧双角色
needIn  = Ein.length  > 0
needOut = Eout.length > 0

按 |demandIn[d] - demandOut[d]| 降序给侧排序
贪心：该侧 demand 更大的角色若仍缺，则染成该角色
若染完后 needIn 且没有任何 IN 侧 → 把 demandIn 最大且仍 UNUSED 的侧改 IN
同理补 OUT
剩余 UNUSED
```

`facing` 与现行 `backFacing` 同一套点积，只是符号取反。染色**不看折弯**——折弯是阶段②的事。

canonical `p1` 预期：`demandIn(B,R)` 高、`demandOut(R,B)` 高，两侧冲突时 **OUT 占 R（两出朝右）、IN 占 B（两入从下）**，或相反；无论哪种，A1 成立。现行 0 折弯的「R 既入又出、B 既入又出」在这一步就被排除。

### 2.2 阶段② 边绑定（在已染色的侧上搜）

```
init ← solveAlgebraicPorts 的结果投影到合法侧
       （若初值某端口角色冲突，改绑到该节点同角色的最近合法侧）

coordinate descent（沿用 D3 终止性：Φ 单调 + 有限状态）:
  每条边 e 只在
     sp ∈ { d | role(from,d) = OUT } ∪ { UNUSED 可升级为 OUT 且不破坏 A1 }
     tp ∈ { d | role(to,d)   = IN  } ∪ { UNUSED 可升级为 IN  且不破坏 A1 }
  中枚举，取 cost = 1000·back + 100·bends + 0.01·len 最小者
  升级 UNUSED → IN/OUT 时写回 role（仍禁止把已是 IN 的侧改 OUT，反之亦然）
```

与现行 `optimizePorts` 的差只有一行语义：**候选域先按 role 裁掉，不再对网关放开**。`relaxNodes` 删除。同向复用自然发生——多条边选中同一已染 IN 或 OUT 的侧。

### 2.3 阶段③ 路径

不改 `solveRouteHybrid`。端口一旦 A1 合法，路径层不再用「穿盒换端口」绕回既入又出（A4 兜底只允许穿盒，不允许改 role）。

### 2.4 阶段④ 同向共干（A3 / M8）—— 不做槽位错开

侧 `d` 上 k 条同向边 **共用该边几何中点**（发布版口径）。出线共一段走廊，需要分叉时再离开共干；入边共一个城门、一支箭头。

槽位 `i/(k+1)` 会把共线拆成平行参差（菱形右侧双出、合规竖线折一下），与「同向可复用」的视觉意图相反，**不采用**。

## 3. 子流程：同一套 3×3，只是尺度不同

不要在 `miniH` / `pad` 上打补丁。内图是外层问题的缩放实例：

| 外层 | 内层 |
|:--|:--|
| `half = 34`，`NODE_BASE.task = 120×44` | `innerHalf ≥ 8`，迷你节点 ≥ 可读下限（字号 11，盒约 72×20） |
| 绘制格 = 节点 + 2×half | 同构：迷你节点 + 2×innerHalf |
| WSAD 染色 + 绑定 + `solveRouteHybrid` | **调用同一套函数**，boxes = 内部节点盒 |
| `CellOrder` / vh | 用**内部边**做 CellOrder，**禁止**用文档级 `Layout` 当铺排方向（AUD-151） |
| `titleH` 独立通栏 | 子流程标题占**独立标题带**，从框高里划出，不与内部格重叠（AUD-150） |

框尺寸：

```
innerCellW = miniW + 2*innerHalf
innerCellH = miniH + 2*innerHalf
boxW = cols * innerCellW
boxH = titleBand + rows * innerCellH
```

然后交给外层 ③：`halfW/halfH = max(文字度量, box/2)`，整列整行扩展照旧。这样「整数倍格、影响泳道」仍然成立，内部不再是 140×48 空壳里塞 72×14 缩略图。

内部边禁止中心穿心模板；零长 stub 视为实现错误（G4 增补）。

## 6. 性能（数学核分层，不是减功能）

打开 canonical 示例原先 **~5.5s** 在 `optimizePorts`：每边 16 端口对 × 迭代 × `solveRouteHybrid`（代数+可见图 Dijkstra）。

现行分层：

| 阶段 | 内核 | 复杂度意图 |
|:--|:--|:--|
| 端口下降 | **仅** `solveAlgebraicRoute` + 路径缓存 | D3 在代数势能上交替；不跑 Dijkstra |
| 最终渲染 | 代数路径若折弯 ≤2（三折线上界）直接采用；否则再跑可见图 | 多数边 0/1/2 弯，Dijkstra 为稀有路径 |

实测（canonical，单次 `flowToSVG`）：布局 ~2ms，端口下降 ~160ms，整图 SVG **~150ms**（约 35×）。
