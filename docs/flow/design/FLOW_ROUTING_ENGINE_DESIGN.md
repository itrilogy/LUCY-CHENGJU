## 0. 摘要

本设计把连线从"一次分配+静态避障"升级为**数学化的迭代最优路径引擎**，严格对齐前提3：
- **端口分配（出入口互斥）**：全局约束，入端口/出端口不共用一侧，且优先朝向"面向对方"的一侧。
- **路径生成（开销最小）**：正交曼哈顿路径，代价 = 穿越节点数×大权重 + 弯折数×中权重 + 走廊占用长度×小权重。
- **迭代重绘（演算）**：初解 → 检测全局碰撞（路径×节点盒、路径×已占用走廊、端口冲突）→ 对碰撞边做局部重排（抬高/绕行/换端口）→ 迭代直到无碰撞或达上限 → 收敛。

## 1. 数学模型

### 1.1 网格与坐标
沿用 `computeExcelLayout` 的确定性网格：
- 绘制格宽 `pw_ci = colWPx[ci] / colNxMax[ci]`，绘制格高 `ph_ri = rowHPx[ri] / rowNyMax[ri]`。
- 节点中心 `(cx, cy)` 严格居中于绘制格。节点自身尺寸 `(W,H)` 由 `nodeMetrics` 决定（子流程已按内部 child 等比例缩放，见前提2）。
- 走廊（连线区）为节点四周 `half` 宽度的带状区域，路径端点落在走廊中线。

### 1.2 端口模型
每个节点有 4 个端口 `P = {T, B, L, R}`。端口坐标：
```
portXY(n, dir) = 节点边界外 half/2 处（走廊中线）
```
- **入端口集合** `in(n)`：当前已分配给"进入 n 的边"的端口。
- **出端口集合** `out(n)`：当前已分配给"从 n 出发的边"的端口。
- **独占约束（出入口互斥，前提3核心）**：
  `in(n) ∩ out(n) = ∅`，且每个端口至多服务一条边（除非汇聚/发散节点允许复用）。

### 1.3 路径（正交曼哈顿）
边 `e: a→b` 的路径是格子中轴上的曼哈顿折线 `pts = [p0, p1, ..., pk]`，其中 `p0 = portXY(a, out_port)`、`pk = portXY(b, in_port)`，相邻点共 x 或共 y（正交）。路径各段吸附到 **行列边界**（`colX` / `bandTop` 网格线）或走廊中线，形成格子通道。

### 1.4 代价函数
对一条边 `e` 的路径 `pts`：
```
cost(e) = w_cross × cross_count(pts)
        + w_turn  × turn_count(pts)
        + w_lane  × lane_overlap(pts)
```
| 项 | 权重 | 含义 |
|:---|:---|:---|
| `cross_count` | `w_cross = 100` | 路径穿过的其他节点盒数（应恒为0，越界用高权惩罚） |
| `turn_count` | `w_turn = 3` | 折弯次数（曼哈顿 L=1 弯，U/Z=2~3 弯） |
| `lane_overlap` | `w_lane = 1` | 路径与"已占用走廊线段"的重叠长度（同走廊多条边错位的代价） |
| `length` | `w_len = 0.1` | 总曼哈顿长度（次要） |

**目标**：`minimize Σ_e cost(e)`，subject to 无节点穿越 + 出入口互斥。

## 2. 迭代重绘演算流程（核心）

```
while 迭代次数 < MAX_ITER 且 有碰撞/冲突:
    // 阶段A：端口分配（出入口互斥 + 朝向优先）
    for e in edges:
        入端口 = inert_port(b, 面向a)   # 首选朝向源一侧，避开已占入/出端口
        出端口 = out_port(a, 面向b)     # 首选朝向目标一侧，避开已占出/入端口
    // 阶段B：路径生成（开销最小）
    for e in edges:
        pts[e] = shortest_orthogonal(a, b, 端口, 避开已占用走廊/节点)
    // 阶段C：全局碰撞检测
    collisions = detect_collisions(paths, nodeBoxes, occupiedLanes, portConflicts)
    if collisions.empty: break
    // 阶段D：对碰撞边局部重排（抬高/绕行/换端口），并标记重绘
    for c in collisions:
        e = c.edge
        pts[e] = reroute(e, 提高 w_cross 惩罚, 尝试 alt 端口/绕行)
    迭代次数 += 1
收敛判定: 无碰撞 或 连续 N 轮 cost 不再下降
```

### 2.1 阶段A 端口分配（迭代内首步）
- 入端口：`targetCandidates(b, a)` 返回"面向源 a 一侧"（同行 b 朝 a 走 L/R；同列 b 朝 a 走 T/B）；在 `in(b) ∪ out(b)` 中选首个未占。
- 出端口：`sourceCandidates(a, b)` 返回"面向目标 b 一侧"；在 `out(a) ∪ in(a)` 中选首个未占。
- 若两侧全被占，允许**沿当前朝向降级**（L→T/B 等），但禁止落到"背向目标"的端口（避免同边/背向）。
- **互斥**：同一节点入/出端口集合不相交；汇聚/发散可放宽到同一端口复用（标注 white-list）。

### 2.2 阶段B 路径生成
`shortest_orthogonal(a, b, ...)` 在格子通道上生成正交路径：
1. 同行/同列相邻 → 直线（1 段，0 弯）。
2. 跨行跨列 → L 型（1 弯）或 Z/U 型（2~3 弯），中段吸附列/行边界。
3. 尝试多个候选走廊位置（含 R1 分数档/横向错位），取 `cost` 最小。
4. 若候选均穿节点 → 触发"外侧走廊"绕行（画布外圈）。

### 2.3 阶段C 碰撞检测
对每条边，检测：
- 路径段 × 其他节点盒（`segIntersectsBox`，跳过本边端点）。
- 路径中段走廊 × 已占用走廊集合（`occupiedLaneX/Y`）。
- 端口冲突（`in ∩ out` 被破坏）。

### 2.4 阶段D 局部重排
对碰撞边：
- 抬高 `w_cross` 惩罚，强制绕行更远走廊。
- 尝试替换出/入端口（换一侧）。
- 若多边共享走廊，按走廊占用递增错位（已有 R1 脊线，升级为全局迭代）。

## 3. 与现状的衔接（分阶段实施）

| 阶段 | 改动 | 风险 |
|:---|:---|:---|
| **P3-a 端口互斥增强** | `sourceCandidates`/`targetCandidates` 已改朝向优先；补"入/出集合不相交 + 不准背向"的硬约束，解决残留同边/背向 | 低（在现有分配上加约束） |
| **P3-b 成本最小贪心** | `buildRoute` 多候选取 `cost` 最小（而非首个可用），接入代价函数 | 中（改变部分走线结果，需校验断言） |
| **P3-c 迭代重绘** | 外层迭代：初解→碰撞→局部重排→收敛；改动较大 | 高（可能重写连线段，可能更新走线断言） |
| **P3-d 视觉指向** | 端点 marker 更贴近节点入口（减小走廊间隙或加 marker 尖端补偿），强化"指向性" | 低 |

建议顺序 `P3-a → P3-b → P3-c → P3-d`，每阶段独立 commit + 断言 + 全量回归。

## 5. 待评审问题（需用户确认）

1. **汇聚/发散端口复用**：是否允许一个节点"多入边共用同一入端口"（BPMN 常见），还是严格每端口一条边？默认**允许**（white-list 汇聚点），避免多入边无端口可用。
2. **迭代上限**：MAX_ITER 建议 8~12 轮（复杂度 O(边数×候选×因子)），超限用当前最优解兜底（允许个别穿节点并告警，而非死循环）。
3. **视觉指向增强**：P3-d 是否要做——缩短走廊间隙（`half/2` → `half/4`）或用 marker 尖端补偿，使箭头尖触节点入口。默认**建议做**（直接回应"箭头不指向入口"）。
