# IQS-Flow 连线走廊「障碍格正方向腾挪」算法说明（设计）

> **文档状态**: 设计说明 / 待评审（未实施）
> **设计日期**: 2026-08-31
> **目的**: 让连线"走格子让出的走廊"，而非避障绕到画布边缘。本质是**布局算法在连线层面的一部分**：为连线方向预留走廊 = 把挡路的障碍格子**按方向整体腾挪一个流程绘制格**。
> **关联**: `FLOW_ROUTING_ALGO_STATE.md` §0b 运输模型；`FLOW_LAYOUT_ENGINE_DESIGN.md` ③扩展格。

## 一、直观规则（用户明示）

> **预留走廊，本质是预留流程节点绘制格（障碍格）按方向整体腾挪一个流程绘制格：**

| 情形 | 腾挪动作 |
|:---|:---|
| **右侧阻碍** | 该障碍格所在的**列**（含其下方所有格）**整体下移**一个绘制格 |
| **上方阻碍** | 该障碍格所在的**行**（含其右侧所有格）**整体右移**一个绘制格 |
| **基准** | **以左上位顶点为基准**执行（坐标系原点在左上角） |

**一句话**：连线要在某行走横向走廊，若该行右侧某格被节点占（障碍），就**把该列向下整个腾挪一格**（这一行就空出走廊）；同理，连线要在某列走纵向走廊，若上方某格是障碍，就**把该行向右整个腾挪一格**（这一列空出走廊）。

## 二、数学表示

### 2.1 坐标系
- 网格矩阵 `(r, c)`，`r=0..R-1` 行、`c=0..C-1` 列；**左上位顶点 = (0,0)** 为基准原点。
- **流程绘制格单位**：
  - 绘制格宽 `pw_ci = colWPx[ci] / colNxMax[ci] = 节点宽 + 2×half`（含左右走廊）
  - 绘制格高 `ph_ri = rowHPx[ri] / rowNyMax[ri] = 节点高 + 2×half`（含上下走廊）
- 节点中心 `node(r,c)` 在绘制格内居中：`cx = colX[c] + gridX*pw + pw/2`。

### 2.2 腾挪变换（障碍按方向整体平移 1 绘制格）
设连线路径需穿过行 `r*`（横向走廊）或列 `c*`（纵向走廊）。
- **右侧阻碍**（障碍在 `(r*, b)` 且 `b > c*`）：该列 `b` **及 `r*` 下方所有行** 的节点，纵向 +`ph`（下移一绘制格）：
  ```
  ∀ 节点 n 满足 n.c == b 且 n.r >= r*：n.y += ph_r*（下移 ph）
  ```
  （即"该列含其下"整体下移，空出 `r*` 行的横向走廊。）
- **上方阻碍**（障碍在 `(a, c*)` 且 `a < r*`）：该行 `a` **及 `c*` 右侧所有列** 的节点，横向 +`pw`（右移一绘制格）：
  ```
  ∀ 节点 n 满足 n.r == a 且 n.c >= c*：n.x += pw_c*（右移 pw）
  ```
  （即"该行含其右"整体右移，空出 `c*` 列的纵向走廊。）

> 符号约定：`ph` 用被让行 `r*` 的绘制格高；`pw` 用被让列 `c*` 的绘制格宽（统一整列/整行，与③扩展格一致）。

### 2.3 关键性质
1. **整列/整行统一腾挪**：腾挪以"列"或"行"为单位（含其下/其右的全部格），不破坏 ③ 的"整行/整列统一扩展"。
2. **正方向腾挪**：障碍朝"远离路线"的正方向推（右侧→下、上方→右），保证让出的是**路线正前方的走廊**，且不会把障碍推向路线。
3. **左上位为基准**：所有位移以上左顶点 (0,0) 为参照，方向统一（下=+y、右=+x），便于数学表达与实现。
4. **不覆盖重排**：腾挪后节点仍居中于"新绘制格"（重新计算 nodePos），保持节点绝不重叠、不超格。

## 三、算法步骤（直白）

```
输入: nodes(网格) + edges(连线意图)
输出: 腾挪后的 nodePos(为连线预留走廊)

1. 对每条边 e: a→b，先按运输模型①建立初始调运路线(直线/折线)。
2. 遍历路线经过的格子 (r*, c*)：
   若该格被节点占（障碍）:
     A. 走廊为横向(在行 r* 走)：
        判定右侧最近障碍列 b>c* → 该列 b 及 r* 下方所有格  整体 y += ph(下移)
     B. 走廊为纵向(在列 c* 走)：
        判定上方最近障碍行 a<r* → 该行 a 及 c* 右侧所有格  整体 x += pw(右移)
3. 腾挪后，对受影响的节点重算绘制格位置(仍取格子中心，居中不超格)。
4. 重复直到所有连线都有走廊(无避障绕行)；再走运输模型③(交汇合并)+④(箭头交接)。
```

### 3.1 判定"右侧阻碍"的候选
- 对横向走廊行 `r*`，从连线列 `c0` 往右找**第一个**被节点占的列 `b`（`b>c0`），该列即腾挪对象。
- 同理"上方阻碍"：从连线行 `r0` 往上找**第一个**被占行 `a`（`a<r0`），该行即腾挪对象。

### 3.2 与现有扩展格（③）的整合
- 腾挪是**在 ③ 行列宽高已算出之后**进行的一次**位移调整**（不重算 colWpx/rowHpx，只整体平移 nodePos 使走廊空出）。
- 若腾挪后某格原节点被推挤出画布 → 该方向再追加一个绘制格的列宽/行高（扩展格同步 +1），保证不越界。
