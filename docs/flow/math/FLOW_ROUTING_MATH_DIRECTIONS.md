# 路径 B 布线内核 · 数学解法方向建议

> **目的**：在 L4 内核（可见图 + 状态 Dijkstra）已定案的基础上，从**数学**角度给出可推进的解法方向、可证性质与验证路径。
> **配套**：`FLOW_ROUTERB_WORKLOG.md`（W1–W4 执行记录）· `FLOW_AUDIT_FINDINGS.md`（R1–R12）
> **验收口径（已定）**：**按布局分别定标** —— 当前布局 Σ折弯 ≤ 20（实测 **16 ✅**）；方案 B 布局以其自身基线（实测 **35**）为参照改进

---

## 1. 当前内核的形式化

### 1.1 状态空间与目标

L4 内核 = 在通道网格上的**状态图最短路**：

- **状态**：`(x, y, dir)`，`x ∈ Xmesh ∪ {s1.x, t1.x}`，`y ∈ Ymesh ∪ {s1.y, t1.y}`，`dir ∈ {H, V}`
- **转移**：沿 `dir` 推进到相邻网格点（代价 `lenWeight·dist`）；90° 转向（代价 `bendCost`）；逆 180° 由非负性天然排除
- **约束（硬）**：任一段与障碍盒相交即剪枝（A4）
- **目标**：`Φ(e) = lexicographic(bends(e), length(e))` —— 当前以 `100·bends + 0.01·len` 近似（强字典序）

### 1.2 复杂度边界（诚实声明）

| 范围 | 复杂度 | 说明 |
|:--|:--|:--|
| **单边**（端口固定） | **多项式可解** | Dijkstra，`O(|S| log |S|)` |
| **全局**（多边 + 共享走廊无冲突） | **NP-hard** | multi-commodity flow（VLSI 已证）；与布局耦合后更是 NP-hard |
| **当前实现** | **逐边独立最短路（sequential）** | 边间**无耦合**，故不承诺全局最优 |

> **结论**：全局最优不可求。可行的数学路线是**「扩张解空间」+「迭代改进」**两条腿；下面 6 个方向均可归入其一。

## 2. 六个方向（含可证性质）

| # | 方向 | 数学形式 | 可证性质 | 收益 | 工作量 |
|:--|:--|:--|:--|:--|:--|
| **D1** | 通道多轨道（**不带**占用代价） | 通道线 `x → {x + kδ}`，`k ∈ [−K, K]` | **单调性引理**（§3.1）⇒ **必然不劣** | 折弯 ↓ | **小** |
| **D2** | 动态 stub 长度 | `λ(e) = dist(p0, 最近通道线)` 取代固定 `half` | **吸附完备性**（§3.2）⇒ R4 = 100% | 吸附达标 | **小** |
| **D3** | 端口联合优化（坐标下降） | 迭代：固定端口求路径 → 以路径代价重估端口对 → 收敛 | **Φ 单调不增 + 有限状态 ⇒ 终止**（§3.3） | 折弯 ↓↓ | 中 |
| **D4** | Rip-up & Reroute | 顺序最短路 → 选最差边 → 移除并重路由（考虑已占资源） | **单调下降 + 有限状态 ⇒ 终止**；不动点 = 局部最优 | 全局质量 ↑ | 中 |
| **D5** | VPSC 分离约束（nudging 真解） | `min Σwᵢ(xᵢ−xᵢ*)²` s.t. `xⱼ − xᵢ ≥ d`；**沿 x/y 可分解为两个一维问题** | 凸 QP；active-set **O(n log n)** | 叠线 → 0 | 中大 |
| **D6** | 布局×布线联合（帕累托） | 扫描通道宽度/溢出策略 → 画 `(面积, Σ折弯)` 前沿 | —（决策支持，非优化） | 方案 B 35 ↓ | 中 |

### D1 详述：为什么 v2 失败而 D1 应成功

R10 的 v2（轨道网格 + 搜索期占用代价）实测折弯 44/66，**劣于**单通道基线（26/10）。当时归因于"轨道与布局不匹配"（AUD-096，**已在 R11 推翻**）。真实归因（R11）：

> **v2 把两件事捆绑了** ——「扩张解空间」（有益）与「搜索期占用代价」（有害）。占用代价惩罚了**合法的共享走廊**（多条边本应共走主干），迫使路径绕行。

**D1 = 只取前半**（扩张解空间，去掉占用代价）。由 §3.1 的单调性引理，这在数学上**必然不劣**。

### D5 详述：nudging 的可分解性（这是它可解的关键）

R12 的结论是"简化 nudging 不可用（被安全约束锁死）"。数学上它有**干净的解法**：

1. **变量**：每条可偏移线段的坐标（垂直段取 `x`，水平段取 `y`）
2. **目标**：最小化总位移 `min Σ wᵢ (xᵢ − xᵢ*)²`（`xᵢ*` = 当前坐标，即"离原位最近"）
3. **约束**：同通道内相邻线段 `xⱼ − xᵢ ≥ d`（`d` = `idealNudgingDistance`）
4. **关键性质**：约束**只沿一个轴** ⇒ 垂直段问题（x 轴）与水平段问题（y 轴）**完全独立**，可分别求解 ⇒ 维度从 2D 降为 **2 × 1D**
5. **一维分离约束二次规划 = VPSC**，active-set 方法 **O(n log n)** 可解（`libvpsc` 即此）

> 这正是 libavoid 的做法（`buildOrthogonalNudgingSegments` → `linesort` → vpsc）。R12 的"简化版"失败，是因为用**局部贪心 + 硬裁剪**替代了**全局凸优化** —— 凸性正是保证"错开 + 不引入新折弯 + 不破坏吸附"三者同时成立的前提。

## 3. 三个可证引理（构成方向的理论依据）

### 3.1 单调性引理（解空间扩张）

> 设 `X ⊆ X′` 是两组候选通道，`Φ*(X)`、`Φ*(X′)` 为对应最优代价，则 **`Φ*(X′) ≤ Φ*(X)`**。

**证明**：`X` 上的可行路径集 `P(X) ⊆ P(X′)`（因 `X′` 的网格图包含 `X` 的网格图）⇒ 在更大的可行集上取 `min`，值不减反降。∎

**推论（指导 D1）**：多轨道扩展**在不施加占用代价时必然不劣** ⇒ v2 的劣化 100% 来自占用代价，与解空间扩张本身无关。

### 3.2 吸附完备性（指导 D2）

> 若 `λ(e) = dist(p0, x_nearest)`（`x_nearest` 为沿端口法向最近的通道线），则 `s1` 落在通道网格上 ⇒ **所有拐点（含 stub 端点）都在网格上**，吸附率 = 100%。

**证明**：`s1 = p0 + λ·n(sp)`，沿法向移动故 `s1` 与 `p0` 同处该法向线上；取 `λ` 恰为到最近通道线的距离 ⇒ `s1` 落在该通道线上。∎

**当前缺陷**：`λ ≡ half`（固定 34px），一般**不**落在任何通道线上 ⇒ 吸附率 27%~100% 随布局波动（AUD-089）。

### 3.3 坐标下降的终止性（指导 D3）

> 交替优化 (a) 端口对 `(sp, tp)` 与 (b) 路径 `π`：每轮固定一者优化另一者，`Φ` **单调不增**；因状态空间有限，迭代**必然终止**于不动点（= 该邻域下局部最优）。

**证明**：每次子问题取其条件下的最小值 ⇒ `Φ` 不增；`Φ` 取值于有限集 ⇒ 收敛。∎

## 4. 优先级与验证路径

| 序 | 方向 | 前置 | 验证方法 | 判定基准（按布局分别定标） |
|:--|:--|:--|:--|:--|
| 1 | **D1 多轨道** | 无 | `compareC.mjs` 增加 `routeD1`（多轨道 + 纯 Dijkstra，无占用代价） | **Σ折弯 ≤ 当前内核**（当前布局 16；方案 B 35）—— 由 §3.1 保证 |
| 2 | **D2 动态 stub** | 无 | 吸附率统计（`diag_hit.mjs` 口径） | **吸附 = 100%** |
| 3 | **D6 帕累托** | 无 | 扫描 `cellW/cellH` 与溢出策略 → 输出 `(面积, Σ折弯)` 表 | 为方案 B 布局选点提供依据 |
| 4 | **D3 端口联合** | D1 | 坐标下降迭代，记录 `Φ` 曲线 | `Φ` 单调不增且收敛 |
| 5 | **D4 Rip-up** | D1 | 记录迭代轮数、`Σ折弯`、终止判据 | `Σ折弯` 下降且可终止 |
| 6 | **D5 VPSC** | 无（独立） | 叠线数 → 0，且折弯不增 | **叠线 = 0 且 Σ折弯 不增** |

**建议顺序**：`D1 → D2`（均为小改动，且分别由 §3.1/§3.2 保证不劣），随后 `D6`（提供布局决策依据），再视情况投入 `D3/D4`；`D5` 独立并行。

## 5. 与既有方案的对应（保持"参照而非依赖"）

| 本方向 | 既有对应 | 说明 |
|:--|:--|:--|
| D1 多轨道 | libavoid 可见图 + 网格细化 | 本项目节点严格落格 ⇒ 可见图退化为规则网格，实现量小 |
| D4 Rip-up & Reroute | VLSI channel routing 标准启发式 | 有成熟的收敛性讨论 |
| D5 VPSC | `libvpsc`（Adaptagrams）/ `obstacle-router` 的 `linesort` | 凸 QP，可自研（一维 active-set 约 200–300 行） |
| D6 帕累托 | 多目标布局美学研究（Effinger et al.） | 决策支持，非求最优 |

> 以上均为**公开算法路线**，自研实现不构成侵权，且保持软著自主性（见台账 AUD-094 / R9 §5）。

## 6. 不做什么（数学边界）

1. **不承诺全局最优** —— 多商品流 NP-hard（§1.2）；
2. **不把占用代价放入搜索期** —— 违反 §3.1 的正确用法（AUD-100 已证伪）；
3. **不用局部贪心替代凸优化做 nudging** —— AUD-102 已证伪；
4. **不为减折弯而移动节点** —— 违反 P1「节点位置权威」（AUD-086 / AUD-090）。
