# 基础语法 · 字典层 Dict 与索引引用

> **字典是整张流程图的"数据源"**：所有可变内容（部门/阶段/岗位/节点标签/属性值）先集中定义在 `Dict` 数组里，结构层只写索引引用——一处定义、多处引用、修改全局生效。

---

## 1. 基本语法

```
Dict: <字典名>[<值1>,<值2>,<值3>,...]
```

```dsl
Dict: D[信息中心,综合计划科,办公室]      // 部门字典
Dict: P[申请阶段,审批阶段,执行阶段]       // 阶段字典
Dict: R[申请员,部门经理,财务岗]           // 岗位字典
Dict: worker[提交采购申请,填写申请单,归档]  // 自定义字典（节点标签）
Dict: 标准[XX-CX-04,XX-GF-01]            // 自定义字典（SOP 值来源）
```

| 项 | 规则 |
|:---|:---|
| 字典名 | 字母/数字/下划线；**D / P / R 为常设固定命名**，其余为自定义字典 |
| 值 | 任意文本（推荐中文）；元素内可用全角标点；**值不可含半角逗号**（如需用 `，` 全角） |
| 索引 | 从 **0** 开始；`D[0]` 指第一个值 |
| 重复定义 | 同一字典名**不得重复定义**（解析器报错） |

## 2. 常设固定字典 D / P / R

| 保留字 | 语义 | 典型用途 |
|:---|:---|:---|
| `D` | **部门**字典 | 泳道行/列来源、节点归属 |
| `P` | **阶段**字典 | 泳道行/列来源、流程阶段划分 |
| `R` | **岗位**字典 | 岗位标注（`Role` 属性）与图例栏数据源 |

> [!warning] 保留字不可冲突
> D / P / R 是数组保留关键字：作为字典名具有固定语义。自定义字典名**不得与其冲突**（校验 error）。

## 3. 自定义字典

除了 D/P/R，可以按需定义任意字典：

```dsl
Dict: worker[动作一,动作二,动作三]     // 节点标签字典
Dict: 标准[XX-CX-04,XX-GF-01]         // 属性值字典（SOP 值来源）
Dict: 部门组[一组,二组]                // 泳道自定义来源
```

> [!tip] 节点标签不强制走字典
> W 行支持**非字典直接命名**（字面量），如 `W: 提交采购申请`。字典引用（`worker[0]`）与字面量两种模式并存，按需选用（详见 [[11-技巧语法-字典索引范式实战]]）。

## 4. 索引引用（全文档统一形式）

| 形式 | 含义 | 示例 |
|:---|:---|:---|
| `名[i]` | 单个索引 | `D[0]`、`worker[2]` |
| `名[i,j,k]` | 索引列表（Lane from 批量用） | `D[0,1,2,5]`（支持非连续/乱序） |
| `名[*]` | 全部索引（便捷糖） | `P[*]` |

```dsl
W: worker[0]          // 引用 worker 字典第 1 个值
Lane from D[0,1,2,5]  // 批量引用部门字典的 4 个索引
Lane from P[*]        // 全部阶段
```

> [!note] 渲染时展开
> 索引只是"引用"，渲染时全部展开为字典值——图上显示"信息中心"而非 `D[0]`。这也是 canonical JSON 中 `labelRef`（原始引用）与 `label`（展开值）并存的原因。
